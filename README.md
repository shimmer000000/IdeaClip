# IdeaClip

浏览器灵感收藏 + AI 商业模式分析 + 项目孵化。

仓库：https://github.com/shimmer000000/IdeaClip

## 当前范围

当前实现 IC-001 网页截图、IC-002 正文和来源采集、IC-003 完整灵感编辑与组合保存、IC-004 完整灵感管理中心，使用 React、TypeScript、Vite 和 Manifest V3。IC-005 备份恢复、AI 分析及项目孵化未开发。真实 X 和微信页面适配仍有验收限制，详见验证记录。

- 提供插件弹窗、灵感管理页和设置页。
- 已实现手动笔记、读取当前网页标题与链接、编辑、删除、搜索、标签与状态筛选。
- 使用 Dexie + IndexedDB 在本地存储数据。
- 可截取可见页面或拖动选择区域，自动压缩并将图片 Blob 保存在本地，提供预览、重新截图和图片下载。
- 按用户操作提取文章、GitHub README、可读的微信正文和当前 X 主帖，预览、修改并保存为本地采集草稿，可引用已有截图。
- 统一编辑标题、来源、正文、多个截图、个人感悟、待研究问题、分类与标签，支持保存草稿、保存灵感、收藏、修改与删除。
- 未提交编辑独立自动保留，提交使用事务和稳定 ID；重复点击不重复创建笔记，删除笔记保留原图及原采集记录。
- 管理中心支持截图卡片与列表、多图大图预览、组合筛选、分页、批量分类标签收藏和二次确认删除，默认分开展示已保存笔记与草稿。
- AI 分析总开关默认关闭；开启仅保存偏好，不执行分析。
- 未接入模型、API Key、云同步或真正的项目孵化流程。

截图、完整灵感编辑与管理中心已在真实 Chrome 中验收。全面无障碍与 Edge 专项验收仍待后续进行。

## 使用灵感管理中心

从弹窗进入灵感库（`notes.html`）。顶部切换“已保存”“草稿”“全部笔记”，未提交编辑单独在恢复入口中展示，按需加载更多。卡片和列表模式可切换，点击标题或卡片空白处查看完整笔记，点击截图查看大图，多张截图可前后切换。收藏、编辑、原网页与删除入口在每张卡片中。

搜索覆盖标题、采集正文、个人感悟、标签与作者，也可指定搜索范围。多个空格分隔的关键词需全部命中；搜索统一全半角及大小写。来源网站、分类、收藏状态、草稿状态与创建日期范围可以组合，排序支持最新创建、最早创建和最近修改。每页 24 条，搜索输入防抖 250 毫秒。

勾选笔记后可批量修改分类、添加或删除标签、收藏或取消收藏、删除。支持跨页选择；改变搜索或筛选会清空选择。每批最多 500 条，标签用逗号或换行分隔，删除标签按完整名称匹配。批量删除需在确认窗口勾选“我已确认”后再次确认；笔记及其未提交编辑将移除，原图与采集记录保留。

每条笔记独立使用安全事务，一条失败不影响其他条；结果显示成功数与逐条失败原因。分类、标签和收藏修改遇到未提交编辑会跳过该条，请先在编辑页核对并保存。失败条目保留选中，可处理后重试。

## 统一收藏与编辑

1. 在目标网页点击 IdeaClip，选择“收藏当前网页”，打开统一编辑页。
2. 截取可见页面、拖选区域，或展开“选择已有截图”多选原图。
3. 点击“提取正文”，核对采集预览后点击“采用采集内容”。已有正文不会被新采集静默覆盖，也可以选择已有采集或手动填写正文。
4. 输入我的感悟、待研究问题、分类与标签，按需标记收藏。
5. 点击“保存草稿”或“保存灵感”，截图、正文、感悟与来源关联到同一笔记 ID。返回灵感库可继续编辑、查看原网页或删除笔记。

原有独立截图与采集入口保留。在截图或采集预览中点击“整理为灵感”也可进入统一编辑；采集预览里的当前修改会先保存，失败时不会跳走。

编辑页区分“正在保留草稿”“已自动保留未提交草稿”和“已保存灵感”。自动保留不提前覆盖已保存版本；只有出现保留成功提示才确认已写入本地。关闭编辑页或重启浏览器后，可从弹窗或灵感库的“恢复未提交编辑”继续。弹窗显示最近 5 条，灵感库提供全部未提交编辑。同一网页优先恢复最近编辑，另起独立笔记可从灵感库“新建灵感”。

发生空间不足或写入失败时，本页输入保留并明确报错，可重试或复制保留；请勿在失败提示下关闭页面。尚有未落盘编辑时，关闭页面会触发浏览器离开确认并尝试写入。强制结束进程前尚未写入成功的最后输入无法保证恢复。

同字段的并发编辑发生冲突时不会静默覆盖。先复制需要保留的输入，再核对其他窗口；有已保存版本时可通过错误区“重新读取已保存版本”明确放弃本页未提交修改后恢复。删除笔记只移除该笔记、其未提交编辑及分析记录，并清空采集回链；截图 Blob、其他笔记和原始采集保留。

## 使用截图

需要 Chrome / Edge 114 或更新版本。在普通网页点击 IdeaClip 扩展图标，选择“截取可见页面”或“选择区域截图”。拖动鼠标后松开完成区域截图，Esc / 右键取消；选区期间页面滚动、窗口尺寸变化或切换标签会取消选区。

独立截图完成后自动打开预览，显示本地保存状态；可下载图片或重新截图。重新截图保留原图。关闭预览后可从弹窗的“最近截图”重新打开最近一张图片。在统一编辑页截图时，图片直接关联到当前未提交编辑并返回该页面。

截图长边最多 2560 像素，单张最多 2 MB；先按实际截图尺寸裁剪，再按需缩小，以 PNG 或 WebP 中更小的格式保存（WebP 可能有损）。截图操作本身不采集正文。浏览器内部页、扩展商店和无权限页面明确提示失败。浏览器菜单的页面缩放受支持；触控捏合缩放需退出后再截图。区域不是整页长截图。

## 使用正文采集

在目标网页点击扩展图标，选择“提取网页内容”。预览显示来源平台与网站、标题、原始 URL、正文、可识别的作者和发布时间、图片 URL 与说明、视频封面、外部链接、GitHub 项目链接和采集时间。未识别字段保持为空并提示，不推断缺失内容。

在预览中修改字段或手动粘贴正文，再点击“保存采集修改”，或直接点击“整理为灵感”（会先保存当前采集修改）。可多选已有截图；仅保存截图 ID 引用，不复制、改写或删除原图。正式提交笔记时，采集的 `noteId` 回链与笔记在同一事务中写入。可从弹窗“最近采集”重开最近采集草稿。

- X：按当前 URL 中的帖子 ID 与主帖时间链接定位，排除推荐帖、引用帖与回复；保留原始帖子 URL（另有不可改写的 `originalUrl` 记录采集时地址）。只读取当前已展开的内容，检测到“显示更多”会提示先在原页面手动展开，再从插件重新提取。
- 普通网页：使用 [Mozilla Readability](https://github.com/mozilla/readability) 与语义正文节点，过滤常见导航、广告、推荐、评论、表单、隐藏和折叠内容；网站结构变化仍可能导致提取不完整。
- GitHub：优先 README，无 README 时仅尝试可见简介并标记“部分内容”；作者字段指仓库所有者，不推断创建时间。
- 微信：仅提取允许访问且可读的 `#js_content` 等页面节点，不读取隐藏脚本数据或绕过验证。
- 未取得正文、权限不足或页面跳转时显示明确提示，并允许手动补充。手动补充会记录来源，不会把原始自动采集状态改成“通过”。

所有预览均为纯文本，不执行页面 HTML；图片与封面仅记录 URL，不自动下载远程媒体，不下载视频。正文最多 100000 字符、链接最多 200 条、图片最多 100 项，自动提取达到上限时标记截断。不保证完整线程、未展开长文、跨页文章、封闭 Shadow DOM 或受限内容的完整性。

## 本地运行

推荐 Node.js 24 LTS（最低 22.12）与 npm。

```sh
npm ci
npm run dev
# 浏览器访问终端显示的本地地址下的 /popup.html、/notes.html、/settings.html
npm test
npm run build
npm run test:e2e
# 允许网络访问时单独运行真实网页验证（不属于确定性离线测试）
npm run test:live
```

`dev` 是普通网页预览；读取当前网页等 Chrome API 需要在扩展环境中使用。

在 Chrome / Edge 打开 `chrome://extensions` / `edge://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选择项目的 `dist/` 目录。修改代码后重新构建并刷新扩展。

## 数据与隐私

- 数据库 `ideaclip`，schema v5：保留 v1 至 v4 的既有表和数据；新增轻量管理目录 `noteCatalog`、文本搜索索引 `noteSearch`、未提交编辑目录 `draftCatalog`、变更版本 `libraryState` 和缩略图缓存 `screenshotThumbs`。迁移分块构建辅助索引，不改写或删除原笔记、原图和采集。
- 旧笔记 `body` 原样保留为“我的感悟”，`content` 是独立采集正文。迁移不更改旧笔记 ID、标签、创建与更新时间，不清空截图或采集，也不重置用户设置。
- 完整笔记保存时，笔记、未提交编辑状态、采集回链与截图存在性校验位于同一事务。失败整体回滚；重复提交同一内容不会创建新笔记或反复变更时间。
- 图片只保存 Blob 与稳定 ID，object URL 仅用于临时预览并在使用结束后释放。永久删除图片的存储接口会拒绝仍被笔记、未提交编辑或采集引用的文件；编辑中的“移除截图”只解除本条关联。
- 笔记按 URL、状态、时间及多值标签建立索引；分析与项目表仅预留结构。
- 管理查询在本地 Worker 中分块运行，仅缓存轻量目录，正文搜索按需分块读取文本索引。索引与原笔记同事务更新；辅助索引会增加本地占用。首次升级构建索引期间请等待，空间不足时明确报错，不删除原数据库。
- 缩略图最长边 480 像素，进入可视区域附近才生成或加载，生成任务最多并发 2 个；完整原图只在大图查看器按当前图片读取。预览离开视口、切图和关闭后释放 object URL。
- 弹窗和其他扩展页面共享同一扩展来源下的 IndexedDB。普通网页预览与扩展数据隔离。
- 仅申请 `activeTab` 与 `scripting`：用于用户触发的截图、视口读取与内容采集；无持久网站访问权限，无自动后台采集。IC-002 至 IC-004 均没有新增权限。
- 扩展 CSP 使用 `connect-src 'none'`，当前版本禁止外部网络连接。
- 不配置任何密钥，不将私有笔记、数据库、截图或导出文件提交到 Git。
- `.gitignore` 只是辅助措施；每次提交前仍须检查内容。不要把密钥放入源码或 `VITE_*` 变量，它们可被打包进入前端。
- 数据未加密、没有备份或跨设备同步。卸载扩展或清除数据将丢失笔记。
