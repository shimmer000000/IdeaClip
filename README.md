## 深度研究方案与来源管理（IC-013 第一阶段）

从灵感库导航进入“深度研究”，或在已保存灵感、项目资料、AI 报告和对比报告中点击同名入口。研究与原记录通过稳定 ID、标题和来源时间关联，研究资料还可以勾选关联到多个来源。最近 100 条来源可直接选择，也可填写记录 ID；草稿和缺失记录不能新关联。

1. 填写研究名称和目标，点击“生成研究提纲（本地规则）”，得到研究问题、关键词、竞品调查和 GitHub 核查四种不同清单，可逐项修改。它使用研究名称生成提纲，不分析正文、不调用 AI，也不声称已完成调查。
2. 手动添加公开网页 URL、标题、摘录、核对证据和备注，选择原始事实、作者主张、AI 推测或待验证假设。原始事实须附摘录和证据，标签仍只代表用户标注、未经独立核验。AI 推测本阶段由用户手动记录，不是本功能生成的模型结论。
3. 保存时原子提交并保留历史，同内容重复保存不新增版本。可只读查看历史、以旧版继续编辑并保存为新版本，导出指定版本 Markdown，或二次确认删除研究。来源变化/缺失只提示，不覆盖旧快照；删除研究不影响原始灵感、项目或报告。
4. 设置页的完整 ZIP v4 包含研究资料、引用及全部历史；继续读取旧 v1–v3。合并冲突保留本地，完整替换需二次确认，失败事务回滚。仍排除密钥、AI 配置、预算账本和本机执行授权。

研究操作支持 AI 关闭时使用，不请求网站权限、不后台联网、不下载媒体、不上传资料、不执行网页命令。只有主动点击“打开公开来源”才由浏览器导航；URL 检查不代表已验证该页面公开可访问。未保存编辑仅在当前页，离开前会提示，请主动保存。单研究上限 50 个版本、100 条资料、100 个关联、2 MiB；超限明确报错并保留原数据。详见 [IC-013 验收记录](docs/IC-013-VALIDATION.md)。

2. 主动启用联网，填写问题及最多3个搜索词、5个公开HTTPS URL，预览计划/全部操作/来源范围/请求数和费用，勾选本次确认才执行。搜索摘要不会自动抓全文；主动加入待读URL后，再预览确认。浏览器不直接抓任意网站、不扫描历史或其他标签页。

4. 选择1～10份已获取资料，开启并配置原AI服务，独立预览精确资料、模型、Token和AI费用后逐次确认。AIEngine生成8栏结构化报告，只能引用实际来源ID和逐字证据，区分来源原文、作者主张、AI推断和假设。报告保存历史、复制和Markdown导出；保存失败可重试写入而不再请求模型。
5. ZIP v5包含研究来源、报告快照和任务只读历史，兼容v1–v4。代理/AI密钥、配置、预算不导出，恢复不授予执行权；研究/AI账本分别限制，不自动退回未知费用。浏览器重启仅恢复历史，不自动执行。

2. 核对白名单和费用，进入采集后沿用原代理配置、免费连接检查、3次搜索/5页上限及逐次预览确认。可以暂停/取消；新增待读URL仍需再次确认。请求草稿可主动保存，不会自动执行。
3. 按已读取/部分读取/仅摘要/不可读取/失败筛选，查看问题、时间、摘录、哈希及信息缺口。选择1～10份资料并明确人工审核，才可进入AI综合；有来源不是事实已核实。
4. 配置并开启原AI总开关，确认具体模型、资料、Token及费用后由AIEngine生成十二栏商业机会报告，保留逐字证据、反证与未知。来源/计划/审核快照变化会使旧确认失效。旧八栏研究报告继续显示，报告支持历史、复制和Markdown。若报告已保存而步骤更新前窗口关闭，可主动使用已保存报告继续，不再调用AI。
5. 选择报告生成可编辑项目草稿；人工审核后才创建项目和任务。项目保留研究/报告软引用、风险和任务建议，可进入原孵化中心复制中文Codex指令。不会执行代码或创建GitHub仓库；同一向导重复提交不会创建第二个项目。

每次保存保留向导步骤历史（最多100条），研究中心可重新进入已保存向导。未保存输入离开前请主动保存，超限会报错。浏览器关闭、权限/预算变化或恢复备份不会自动恢复请求，未知费用不重发。Dexie v14仅新增向导表；ZIP v6包含进度、历史、项目草稿与报告，兼容v1–v5，导入清除审核及请求URL，退回审核步骤，不恢复付费执行授权。

完整流程只用Mock搜索/AI验证，真实Brave和模型仍待逐次费用授权；详见 [IC-015验收](docs/IC-015-VALIDATION.md)。

## 项目孵化中心（IC-011）

1. 从灵感管理中心进入“项目孵化中心”，手动创建项目；也可在完整笔记、已保存 AI 报告或对比报告点击创建入口。中心提供最近 100 条来源的选择，也可按记录 ID 定位。创建和编辑均在本地，不要求开启 AI。
2. 填写项目名称、描述、目标用户、核心需求、商业模式假设、MVP、预计成本和验证目标，保存项目。手动调整研究、需求验证、MVP、用户测试、商业化、扩展、暂停或终止阶段；变更历史自动保留。多窗口旧编辑不会覆盖新数据，失败时输入保留。
3. 新增任务，设置优先级、状态、截止日期、备注、关联灵感、阶段里程碑与验收标准。支持看板/列表、编辑/删除与完成进度；手动审核任务后才能复制包含背景、目标、技术要求、范围、验收、测试和 Git 要求的中文 Codex 指令。复制不会执行代码或创建仓库。
4. 需要 AI 时，先按原流程开启并配置服务商。选择至多 10 条已保存灵感（可留空，仅用项目资料），点击“生成项目计划：预览与费用”。核对完整资料、模板、端点、Token 与费用后逐次确认；不发送截图、旧方案、任务或阶段历史，不进入自动队列。
5. AI 使用现有 Skills 结构与引擎，生成 MVP、架构、开发任务、验收、7/30/90 天计划和风险/停止条件，保存为独立待审核方案。不会覆盖项目字段或改变阶段。生成后重新读取项目，逐项选任务并勾选人工审核，才可新增导入；相同方案任务重复确认或删除后再导入均跳过，方案历史继续保留。
6. 项目、任务、阶段历史、方案与来源引用包含在完整 ZIP 中。Dexie v11 增量保留旧项目；兼容旧 ZIP。删除来源只提示缺失，删除项目不会删除原始笔记与报告。备份不携带 Key、AI 服务配置、预算或自动执行授权。

项目最多 500 任务、50 份方案、1000 条阶段历史；每份方案最多 8 条开发任务。超过限制明确报错。项目资料需主动保存；关闭页面会丢失尚未保存的项目/任务输入。长期大规模项目和全面无障碍仍需后续验收。详见 [IC-011 验收](docs/IC-011-VALIDATION.md)。

## 商业机会横向对比（IC-010）

在灵感管理中心勾选 2～10 条已保存灵感，点击“商业机会对比”。可查看标题、来源、正文质量及完整文字，移除或调整顺序。草稿、缺失记录和未提交编辑不能发送；超出 200000 UTF-8 字节时要求缩减，不自动截断。

资金、开发、获客、盈利与风险权重可在本地重算排名，不增加 AI 请求；权重仅为当前查看偏好，重新打开历史恢复等权。评分越高代表条件越有利，未经市场验证。原建议不会因改权重变成新分析；需要新分析必须重新预览确认。

报告自动保存到独立历史，保存失败可在当前页重试保存、复制或导出 Markdown。来源变化或删除后旧报告仍保留并提示；完整 ZIP v3 包含报告和脱敏来源快照，并兼容旧备份。详见 [IC-010 验收](docs/IC-010-VALIDATION.md)。

5. 报告保存模板 ID/版本和定义快照；同一笔记可保留不同模板的多个报告，支持证据摘录、事实/推测/假设标识、复制和 Markdown 导出。Codex 模板额外可复制完整中文开发指令，需核对后自行使用，不会自动执行。
6. 自动分析使用已明确指定的默认模板，保存自动模式时另行确认。修改、删除、启停模板或更换默认项会取消客户端请求、暂停等待任务并使旧授权失效；重新授权不会把旧任务自动换成新模板，也不会重复发送付费请求。
7. 模板 JSON 导入为新 ID 的停用副本；完整 ZIP v2 包含自定义模板和历史报告，恢复后模板停用，不携带本机执行授权。旧 ZIP v1 和旧报告继续兼容；默认选择保留为本机设置，恢复后须重新选择或确认。

实现边界与测试记录见 [IC-009 验收](docs/IC-009-VALIDATION.md)。模板是受限分析偏好，不是可执行的 Codex Skill 或联网研究；项目孵化使用独立的待审核方案入口。

## 使用手动 AI 商业分析

1. 在设置页手动开启 AI 总开关。关闭状态下不创建新请求，开启本身不调用模型。
2. 选择 OpenAI、DeepSeek 或自定义兼容 API。填写模型、完整端点、认证、超时、最大输出、USD 输入/输出估算单价与每日预算，再确认接收方并点击“保存配置并授权域名”。保存配置不发起测试请求；浏览器按域名请求可选权限，拒绝授权则不能分析。
3. 推荐对接自己管理的安全代理，在服务端保管真正的模型 Key。自定义接口兼容 Chat Completions JSON，代理可自行鉴权、不发送客户端 Key；本项目没有部署代理服务。直连时 Bearer Key 只发送至已配置的完整端点，重定向一律拒绝。HTTPS 可用；HTTP 仅允许可信本机代理。
4. Key 默认保存在浏览器会话，浏览器重启后需重填。长期本地保存需勾选风险确认；同机恶意软件、调试权限或浏览器配置泄露可能读取它，不能当作保险箱。清除密钥按钮同时撤销当前域名授权。Key 不回显，不进入笔记、请求日志或 ZIP。
5. 在灵感卡片或完整笔记中打开“AI 分析”，也可从编辑页的“AI 分析与历史”进入。只分析已保存笔记，有未提交编辑时须先保存。仅发送标题、采集正文、个人感悟、来源 URL，不发送其他笔记、历史、分类标签或待研究事项。
6. 截图默认全部不发送。只有在设置中按服务商文档确认该模型支持图像，且用户主动选图并在本次窗口再确认上传，才发送最多 3 张本地截图（每张 ≤2 MiB）。只发送所选图片的 data URL，不请求网页远程媒体。模型能力不会自动探测，不兼容时明确失败，不自动降级重试。
7. 点击预览，核对精确文本、端点、模型、图片、输入 Token 估算及费用。确认本次资料发送和可能产生的费用后，才消耗一次性确认 ID 进入队列。取消预览无模型请求，修改配置或笔记、凭据失效、确认超过 10 分钟需重新预览。
8. 校验后的报告自动保存为独立历史版本，记录模型、时间、来源摘要和图片数量；可切换历史、复制、导出 Markdown、重新确认后分析。报告或日志写入失败不会改动原笔记；报告保留在当前页面，可重试保存、复制或导出，保存重试不调用 AI。

报告包含 15 个栏目：创意总结、用户画像、痛点、定位、商业模式、盈利方式、获客、优势门槛、成本假设、可复制性、风险、7/30/90 天计划及调查问题。输出必须符合 JSON Schema；来源陈述须有发送原文内的逐字证据，标记“未独立核验”，其他内容区分推测和待验证假设。网页和截图里的指令仅作为不可信资料，不提供工具执行能力。模型仍可能推理错误，不保证真实收入、用户数、利润或商业成功。

费用使用用户填写的单价，统一 USD，输入采用 UTF-8 字节数加开销的保守估算，图像采用用户填写的每图 Token 预留，输出按最大 Token 计算。本浏览器按 UTC 日、整数微美元、事务预留并限制并发；超过每日额度时阻止请求。该估算不是实时账单或服务商硬限额，价格、缓存、推理和图像规则可能不同，请自行核对当前价格并设置服务商账户限制。已发送、超时、失败、取消或进程中断的预留不自动退回；浏览器无法保证停止服务商的计费。

关闭总开关、修改配置、清除凭据、恢复数据库或关闭分析页面，会取消客户端请求和队列。关闭 AI 不影响截图、采集、笔记、搜索和备份。设置页显示最近 20 条请求状态、实际返回的 Token（如有）和本地预留；未知结果仍占预算。客户端限制不能防止用户修改本地数据库/时钟或跨设备累计消费。

接口与安全代理约定见 [AI 引擎说明](docs/AI-ENGINE.md)。自动化只使用本机 Mock API，未调用真实付费模型；原生浏览器权限弹窗与真实供应商可用性尚未验收，不能把 Mock 成功视为真实模型已验证。

## 使用自动分析和任务中心

默认仍为手动模式，AI 总开关与自动分析均默认关闭。在设置页“自动分析与浏览辅助”选择模式：

- **保存后自动分析**：填写精确域名白名单及可选黑名单，设置单次预留上限，核对服务商、模型、文本发送范围与每日共享预算后明确授权。只有此后主动点击“保存灵感”的新增或修改版本入队；自动保留编辑、保存草稿、批量整理和浏览页面不触发模型。相同笔记 revision 只建立一条任务；未变更的重复保存不产生费用。
- **浏览辅助模式**：额外逐域授权网站，仅在这些 HTTPS 网站（可信本机可 HTTP）的主框架以本地规则识别工具、SaaS、GitHub、创业文章、X 商业创意。提示不自动保存、采集正文或上传；点击“确认收藏灵感”只打开标题/URL 草稿，用户编辑、勾选本条入队并保存后才能分析。可只开启本地提示、保持自动分析关闭。

白名单不包含子域，黑名单包含子域且优先；密码、银行、私人邮箱、登录/账户/支付/管理页面及敏感字段默认拦截。输入密码、信用卡或验证码的页面不会读取候选正文。规则可能误判或漏判，请主动排除私人域名；不能当作完整的敏感信息识别器。没有来源 URL 的手动灵感须单独授权，浏览辅助不支持此选项。

自动发送仅包含已保存版本的标题、采集正文、个人感悟和脱敏 URL，**始终不发送截图**。15 栏报告保存到原笔记的分析历史，与手动报告一样可查看、复制、导出 Markdown 和备份。手动分析入口与逐张选图确认继续保留。

“AI 任务中心”（`tasks.html`）显示六种状态、失败原因、当前模式及 UTC 今日预留费用，支持暂停、恢复未发送任务、取消单个任务、取消全部等待任务、结果查看及手动重试。后台会打开不抢焦点的执行标签页，请保持任务中心打开；不依赖 MV3 worker 长时间存活。多个执行页通过 Web Locks 串行调度和任务锁防止重复请求。

关闭总开关、停用自动模式、修改授权/服务商/密钥、撤销权限或恢复备份会停止新请求并取消相应客户端请求。暂停期间新保存的版本保留为暂停任务。任何失败均暂停剩余队列；费用不明的任务不自动重试。浏览器重启或执行页中断后，运行任务标记为费用/结果未知，已保存报告可恢复为完成；其余未发任务需人工恢复并重新校验快照、会话和权限。默认会话密钥重启失效时需重填，并重新确认自动授权。

手动重试需要新的完整预览和重复计费确认，不能用“恢复”重发失败/已发送任务。预算与 IC-007 手动分析共享；达到上限后停止，已预留费用不自动退回。队列仅保留稳定 ID、revision 与摘要，不复制笔记正文或图片；待处理任务上限 1000，任务中心每次显示 24 条。超限或写入失败明确提示并保留草稿，不生成一半保存的数据。

架构和验证边界见 [AI 引擎说明](docs/AI-ENGINE.md) 与 [IC-008 验收记录](docs/IC-008-VALIDATION.md)。

## 数据备份、恢复与迁移

1. 进入设置页的“数据备份与恢复”，点击“立即备份”，保存 `IdeaClip-Backup-YYYY-MM-DD.zip`，并确认浏览器下载完成。
2. 在当前或另一浏览器中安装本版本 IdeaClip，点击“从文件恢复”或选择 ZIP 文件。校验通过后预览笔记、截图、未提交草稿、采集、设置、历史分析与项目数量和备份创建时间，尚未修改主数据库。
3. 默认“合并恢复”保留本地数据。稳定 ID 及内容相同的记录去重；内容不同则保留本地并跳过冲突记录和关联分组，防止误连到同 ID 的另一张图片。草稿入口冲突同样保护，设置冲突保留本地。结果显示成功、失败、重复与冲突跳过数。
4. “完整替换”在确认窗口勾选确认后才能执行，会将当前全部业务数据与设置替换为备份版本。请先备份当前数据并关闭其他编辑窗口。校验成功的数据在单一事务中写入，写入失败、取消或浏览器关闭导致事务中断时整体回滚。
5. 成功后自动刷新打开的灵感库；其他已打开的编辑页面请重新打开。恢复的原网页信息保留，旧浏览器标签 ID 清空或置为无效默认值，后续截图需从原网页重新连接。

备份包含所有笔记、正文、感悟、问题、分类标签、草稿收藏状态、未提交编辑、完整原始截图 Blob、采集记录及关联、通用设置和已有分析/项目记录。AI 报告包含 15 栏结构化内容、模型、时间与来源摘要；旧纯文本报告继续保留。索引与缩略图缓存不导出，恢复后自动或按需重建。备份操作不调用 AI、不上传服务器；schema v7 增量迁移，无需重置数据库。

AI 端点配置、密钥和本浏览器预算账本不进入普通 ZIP，迁移到新浏览器需要重新配置和授权。完整替换保留当前设备的 `aiConfig` 与 `aiUsage`，避免通过恢复重置每日预算；恢复前取消未完成 AI 请求。通用 AI 开关偏好仍可恢复，但恢复前暂停自动队列。自动授权和任务元数据不进入备份、不跨设备迁移；完整替换保留当前任务、授权和账本，未发任务须人工恢复，失效快照不会发送。

文件不加密，包含私人笔记和图片，请妥善保管。只导出已知业务字段，API Key、访问令牌等配置字段排除；常见文本凭据及 URL 敏感参数会脱敏，因此这些内容不会逐字恢复。不要在笔记正文或截图里保存秘密，脱敏不能识别所有人为写法或图片中的凭据。仅导入可信来源的备份；校验和用于发现损坏，不是身份签名。

采用无压缩 ZIP，逐文件校验 CRC32、SHA-256、图片签名和尺寸、元数据及引用。最大 512 MiB、10 万条记录、1 万个文件、50 万条关联，每项最多 8 MiB，图片最多 8192 单边且不超过 16777216 像素；超限明确拒绝，不强行装载。源数据关联缺失时停止导出，保留原数据。数据分批读取、散列和校验，原图不转 Base64，不一次性物化全部图片字节。

预览使用隔离临时数据库，需要额外空间；关闭或取消后清理，进程中断留下的闲置暂存库在下次进入设置时清理，其他窗口的活跃预览受锁保护。空间不足会明确报错并保留主数据库。用量按钮显示当前扩展来源下的估算占用和总配额，包含索引、缓存及暂存，不是精确到表的磁盘大小。

兼容备份格式 v1 和 schema 1 至 7 的元数据，补齐早期笔记字段且不将感悟改成正文；未来不兼容版本拒绝导入。详细规则见 [备份格式](docs/BACKUP-FORMAT.md)，备份阶段验证见 [IC-005 验收记录](docs/IC-005-VALIDATION.md)。

## 使用灵感管理中心

从弹窗进入灵感库（`notes.html`）。顶部切换“已保存”“草稿”“全部笔记”，未提交编辑单独在恢复入口中展示，按需加载更多。卡片和列表模式可切换，点击标题或卡片空白处查看完整笔记，点击截图查看大图，多张截图可前后切换。收藏、编辑、原网页与删除入口在每张卡片中。

搜索覆盖标题、采集正文、个人感悟、标签与作者，也可指定搜索范围。多个空格分隔的关键词需全部命中；搜索统一全半角及大小写。来源网站、分类、收藏状态、草稿状态与创建日期范围可以组合，排序支持最新创建、最早创建和最近修改。每页 24 条，搜索输入防抖 250 毫秒。

勾选笔记后可批量修改分类、添加或删除标签、收藏或取消收藏、删除。支持跨页选择；改变搜索或筛选会清空选择。每批最多 500 条，标签用逗号或换行分隔，删除标签按完整名称匹配。批量删除需在确认窗口勾选“我已确认”后再次确认；笔记及其未提交编辑将移除，原图与采集记录保留。

每条笔记独立使用安全事务，一条失败不影响其他条；结果显示成功数与逐条失败原因。分类、标签和收藏修改遇到未提交编辑会跳过该条，请先在编辑页核对并保存。失败条目保留选中，可处理后重试。

## 统一收藏与编辑

1. 在目标网页点击 IdeaClip，选择“收藏当前网页”，打开统一编辑页。
2. 截取可见页面、拖选区域，或展开“选择已有截图”多选原图。
3. 点击“提取正文”，核对采集预览后点击“采用采集内容”。已有正文不会被新采集静默覆盖，也可以选择已有采集或手动填写正文。
4. 输入我的感悟、待研究问题、分类与标签，按需标记收藏。
5. 点击“保存草稿”或“保存灵感”，截图、正文、感悟与来源关联到同一笔记 ID。返回灵感库可继续编辑、查看原网页或删除笔记。

原有独立截图与采集入口保留。在截图或采集预览中点击“整理为灵感”也可进入统一编辑；采集预览里的当前修改会先保存，失败时不会跳走。

编辑页区分“正在保留草稿”“已自动保留未提交草稿”和“已保存灵感”。自动保留不提前覆盖已保存版本；只有出现保留成功提示才确认已写入本地。关闭编辑页或重启浏览器后，可从弹窗或灵感库的“恢复未提交编辑”继续。弹窗显示最近 5 条，灵感库提供全部未提交编辑。同一网页优先恢复最近编辑，另起独立笔记可从灵感库“新建灵感”。

发生空间不足或写入失败时，本页输入保留并明确报错，可重试或复制保留；请勿在失败提示下关闭页面。尚有未落盘编辑时，关闭页面会触发浏览器离开确认并尝试写入。强制结束进程前尚未写入成功的最后输入无法保证恢复。

同字段的并发编辑发生冲突时不会静默覆盖。先复制需要保留的输入，再核对其他窗口；有已保存版本时可通过错误区“重新读取已保存版本”明确放弃本页未提交修改后恢复。删除笔记只移除该笔记、其未提交编辑及分析记录，并清空采集回链；截图 Blob、其他笔记和原始采集保留。

## 使用截图

需要 Chrome / Edge 114 或更新版本。在普通网页点击 IdeaClip 扩展图标，选择“截取可见页面”或“选择区域截图”。拖动鼠标后松开完成区域截图，Esc / 右键取消；选区期间页面滚动、窗口尺寸变化或切换标签会取消选区。

独立截图完成后自动打开预览，显示本地保存状态；可下载图片或重新截图。重新截图保留原图。关闭预览后可从弹窗的“最近截图”重新打开最近一张图片。在统一编辑页截图时，图片直接关联到当前未提交编辑并返回该页面。

截图长边最多 2560 像素，单张最多 2 MB；先按实际截图尺寸裁剪，再按需缩小，以 PNG 或 WebP 中更小的格式保存（WebP 可能有损）。截图操作本身不采集正文。浏览器内部页、扩展商店和无权限页面明确提示失败。浏览器菜单的页面缩放受支持；触控捏合缩放需退出后再截图。区域不是整页长截图。

## 使用正文采集

在目标网页点击扩展图标，选择“提取网页内容”。预览显示来源平台与网站、标题、原始 URL、正文、可识别的作者和发布时间、图片 URL 与说明、视频封面、外部链接、GitHub 项目链接和采集时间。未识别字段保持为空并提示，不推断缺失内容。

在预览中修改字段或手动粘贴正文，再点击“保存采集修改”，或直接点击“整理为灵感”（会先保存当前采集修改）。可多选已有截图；仅保存截图 ID 引用，不复制、改写或删除原图。正式提交笔记时，采集的 `noteId` 回链与笔记在同一事务中写入。可从弹窗“最近采集”重开最近采集草稿。

- X：按当前 URL 中的帖子 ID 与主帖时间链接定位，排除推荐帖、引用帖与回复；保留原始帖子 URL（另有不可改写的 `originalUrl` 记录采集时地址）。只读取当前已展开的内容，检测到“显示更多”会提示先在原页面手动展开，再从插件重新提取。
- 普通网页：使用 [Mozilla Readability](https://github.com/mozilla/readability) 与语义正文节点，过滤常见导航、广告、推荐、评论、表单、隐藏和折叠内容；网站结构变化仍可能导致提取不完整。
- GitHub：优先 README，无 README 时仅尝试可见简介并标记“部分内容”；作者字段指仓库所有者，不推断创建时间。
- 微信：仅提取允许访问且可读的 `#js_content` 等页面节点，不读取隐藏脚本数据或绕过验证。
- 未取得正文、权限不足或页面跳转时显示明确提示，并允许手动补充。手动补充会记录来源，不会把原始自动采集状态改成“通过”。

所有预览均为纯文本，不执行页面 HTML；图片与封面仅记录 URL，不自动下载远程媒体，不下载视频。正文最多 100000 字符、链接最多 200 条、图片最多 100 项，自动提取达到上限时标记截断。不保证完整线程、未展开长文、跨页文章、封闭 Shadow DOM 或受限内容的完整性。

## 数据与隐私

- 数据库 `ideaclip`，schema v7：保留 v1 至 v6 的既有数据，在 AI 配置、预算及分析历史基础上增量新增 `autoPolicy`、`aiTasks`。无删除或重置旧笔记、原图和采集。
- 旧笔记 `body` 原样保留为“我的感悟”，`content` 是独立采集正文。迁移不更改旧笔记 ID、标签、创建与更新时间，不清空截图或采集，也不重置用户设置。
- 完整笔记保存时，笔记、未提交编辑状态、采集回链与截图存在性校验位于同一事务。失败整体回滚；重复提交同一内容不会创建新笔记或反复变更时间。
- 图片只保存 Blob 与稳定 ID，object URL 仅用于临时预览并在使用结束后释放。永久删除图片的存储接口会拒绝仍被笔记、未提交编辑或采集引用的文件；编辑中的“移除截图”只解除本条关联。
- 笔记按 URL、状态、时间及多值标签建立索引；分析表支持历史版本，项目表仍只保留结构和已有数据。
- 管理查询在本地 Worker 中分块运行，仅缓存轻量目录，正文搜索按需分块读取文本索引。索引与原笔记同事务更新；辅助索引会增加本地占用。首次升级构建索引期间请等待，空间不足时明确报错，不删除原数据库。
- 缩略图最长边 480 像素，进入可视区域附近才生成或加载，生成任务最多并发 2 个；完整原图只在大图查看器按当前图片读取。预览离开视口、切图和关闭后释放 object URL。
- 弹窗和其他扩展页面共享同一扩展来源下的 IndexedDB。普通网页预览与扩展数据隔离。
- 安装权限为 `activeTab`、`scripting`、`storage`。IC-007 的 `storage` 用于会话/可选本地凭据；HTTPS 和本机 HTTP 域名列为可选权限，保存配置时只请求对应主机，不在安装时授予全站访问。Chrome 主机权限不区分端口，AI 门禁仍绑定完整端点（含端口、路径）。
- CSP 保留 `script-src 'self'`，无 unsafe-eval 或远程脚本。为自定义兼容 API 允许 HTTPS 和本机 HTTP 连接，AI 引擎在请求前检查用户域名授权、配置版本和逐次确认，不向其他端点自动发送数据。
- 不硬编码密钥，不将私有笔记、数据库、截图、凭据或导出文件提交到 Git；凭据只在受信任扩展上下文使用，默认不持久化。
- `.gitignore` 只是辅助措施；每次提交前仍须检查内容。不要把密钥放入源码或 `VITE_*` 变量，它们可被打包进入前端。
- 数据与备份未加密，无自动云备份或跨设备同步；可用 ZIP 手动迁移。卸载扩展或清除数据前请导出并保存备份。
