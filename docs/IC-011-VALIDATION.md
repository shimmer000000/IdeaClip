# IC-011 项目孵化中心验收

日期：2026-11-07。基线 main：c65eb7844b6c827c0ae64e1faeabf2cf94664dd8。已拉取 main，阅读 AGENTS、README、ROADMAP 和 AI 引擎说明，使用 CodeGraph 检查笔记、Skills、AI 引擎、对比报告、旧项目表和备份。范围仅项目孵化中心，不包含自动 Codex 执行、联网研究、自动建库或云同步。

## 功能

独立管理视图复用 notes.html?projects；灵感管理中心提供入口。支持手动、保存笔记、AI报告、对比报告四类创建，来源可从最近100项选择或输入ID。保存项目ID、名称、描述、目标用户、需求、商业假设、MVP、预计成本、验证目标和时间。创建时描述预填最多10000字符的来源摘要，完整来源引用保留，界面提示用户核对。

八类阶段：研究、需求验证、MVP开发、用户测试、商业化验证、扩展运营、暂停、终止；人工保存改变阶段并保留时间和前后阶段。任务支持新增、修改、删除确认、优先级、状态、截止日期、备注、关联灵感、阶段里程碑、验收标准、完成进度与看板/列表。项目保存使用revision比较和事务，旧编辑不能覆盖其他窗口或AI追加的数据。

项目AI使用现有AIEngine与受限Skills模型，固定builtin-incubation v1.0.0八栏：MVP清单、架构、开发任务、验收、7/30/90天计划和风险/停止条件。只发送保存后的项目业务字段和0–10条主动选择的保存笔记；不发截图、阶段历史、任务或旧方案。预览明示完整文本、端点、模型、Token上界和预算预留，逐次确认才请求，不加入自动队列。200000字节输入限额超限报错，不截断；输出上限为服务商与8192的较小值。

保留总开关、配置/凭据/域名授权、预算锁、超时/取消、无重定向和安全日志；项目整行及所选笔记快照在原引擎多阶段检查，任何变化/删除使授权失效。网页和模板偏好仅作为不可信user数据；没有工具、脚本或命令执行。输出Schema、逐字来源证据和凭据回显检查不变。

AI只追加待审核方案历史，记录ID、模型、时间、模板ID/版本、项目版本与笔记ID/版本/摘要，不改变项目资料或阶段，也不自动导入任务。生成后重新读取并勾选任务与人工审核确认，导入事务再次核对项目版本；planId:index稳定键防止重复，即使删除导入任务仍保留导入标记。方案保存失败保留当前页面结果，重试存储不调用模型。

任务经人工审核后可以复制中文Codex指令，包含项目背景、当前目标、技术要求、范围、验收、测试与Git提交要求；改变任务标题/备注/验收会清除审核标记。复制仅产生文本，未连接Codex执行器、终端或GitHub建库接口。

## 数据与备份

Dexie v11沿用projects，新增字段可选并在读取旧记录时补默认值，不重建/回填旧库。项目业务、任务、阶段历史、方案与来源嵌套保存，单行事务保持一致性。旧笔记、截图、报告、队列和预算保留。

ZIP仍为v3九张业务表，兼容v1/v2以及数据库版本1–11；新项目字段逐项白名单、脱敏与Schema校验，旧五字段项目可原样往返。来源是软引用，删除原笔记/报告后项目仍保留且提示缺失，孤立项目可备份恢复。合并同ID冲突保留本地项目，完整替换必须二次确认，恢复中断原事务整体回滚。不导出Key、服务配置、预算、本机自动策略/执行队列或授权。项目任务和审核状态是业务记录，恢复它们不会执行任务或发送AI。

## 限制与遗留

- 真实付费模型生成质量、不同服务商实际兼容性、Edge、全面无障碍与长时压力未验收，Mock成功不代表真实商业/技术建议可靠。
- 项目上限500任务、50方案、1000阶段历史、100来源引用，方案每栏最多8项；备份仍受单JSON项8MiB等原安全限制。超限明确失败，不丢弃数据；大项目需后续按用户需求评估分表与性能。
- 项目/任务需要主动保存，尚未保存输入只在当前页面保留，关闭页面会丢失；失败不会覆盖已保存内容。项目尚无自动草稿或云同步。
- 来源选择列表展示最近100项，其他历史可用稳定ID；方案保留来源ID/版本/摘要和证据摘录，没有复制全部原始页面作为新的永久快照。来源删除提示缺失，已有项目和方案继续可读。
- 项目AI不会自动重试、改阶段、导入任务、执行Codex、创建GitHub仓库或联网研究。
