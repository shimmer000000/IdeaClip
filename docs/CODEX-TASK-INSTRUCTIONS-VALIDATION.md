# 0.1.2：孵化中心单任务 Codex 指令验收

日期：2026-11-08。范围仅IdeaClip任务指令，不开发Obsidian产品，不修改其他项目，不调用真实AI/搜索，不改变研究出口或费用账本。

## 问题与修复

旧指令重复项目背景/MVP/验证目标，未区分人工研究与代码实现，也没有目标仓库边界。AI方案和研究向导导入任务还会将整份验收或七天验证目标复用到每条任务。

- 三类任务：软件开发、人工研究、验证测试。项目用途独立为测试、真实开发、人工研究；新任务及旧未分类任务默认验证测试，旧类型缺失明确提示只读。
- 只序列化当前任务ID、标题、备注、关联灵感ID、里程碑和验收，以及项目ID/名称；不复制项目描述、完整MVP、完整验证目标、所有任务或完整方案。任务输入标为不可信资料，不构成额外授权。
- 软件开发只允许真实开发项目，要求明确HTTPS仓库地址、绝对工作目录和1～20条仓库内相对路径；拒绝凭据、查询参数、越界、通配符及命令字符。缺失时复制失败，不猜测目标。生成文本要求接收方核对remote、未提交修改、解析后路径和符号链接。
- 人工研究只生成问题、提纲、空白记录模板，真实访谈/问卷数量/市场反馈均为“人工待完成”；禁止将AI模拟当真实反馈。常见混合开发与真实调研任务拒绝复制并提示拆分；问卷编辑页和访谈记录软件模块仍可作为开发任务。
- 验证测试仅以已有功能的隔离验收为目标，不修改代码或真实数据，不自动开发商业产品；修复需另建且绑定开发任务。
- 三类文本均含任务目标、输入资料、执行步骤、禁止事项、验收标准、测试要求、交付结果及适用Git要求。没有执行器，不运行命令、调用付费服务、创建仓库或发布。
- 未保存项目修改不用于复制。修改任务输入/类型取消审核，修改项目用途/执行边界取消任务审核，保留状态和历史。保存失败保留当前输入，复制失败不显示过期成功提示。
- 新导入任务只留单任务验收待填写提示，不附整份计划；检测到旧导入任务直接继承全计划验收时要求人工编辑。不会静默重写旧任务。

## 数据与兼容

项目用途、任务类型和本机workspace均为可选字段，不改变Dexie表或索引，不需新增数据库版本，不重置旧库。原任务、阶段历史、来源、报告和预算均保留。ZIP白名单包含用途/类型，排除workspace中的仓库、私有工作路径与修改范围；恢复后开发指令因缺少边界而拒绝，须本机重新绑定，恢复不构成执行授权。旧ZIP和无类型记录继续可读。

## 使用步骤与限制

1. 编辑当前任务，选择任务类型，只写当前任务的输入/验收并保存。
2. 开发任务先选择真实开发项目，填写目标仓库、工作目录和相对修改范围并保存；随后重新审核任务。测试/人工研究无需绑定开发仓库。
3. 人工审核后点击“复制 Codex 指令”，只复制当前任务文本；下一位执行者仍须核对真实仓库、路径和授权。

本功能仅验证绑定格式，不自动访问仓库或扫描本机文件，因此不能证明目标仓库可达或目录实际属于该remote；这些检查列入接收方执行前步骤。人工研究识别是有限规则，不能替代用户逐条审核。测试不包含真实问卷、访谈、商业产品开发或执行复制出来的指令；这些工作不能标为完成。没有新增依赖、全站权限或付费请求。
