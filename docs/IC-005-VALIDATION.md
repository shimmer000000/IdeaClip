# IC-005 备份恢复验收

范围：设置页本地 ZIP 备份、校验预览、稳定 ID 合并与冲突保护、二次确认完整替换、失败/中断事务回滚与手动迁移。主数据库 schema v5 保留，没有重置数据库、新增浏览器权限、付费 API、AI 请求或用户数据上传。

## 测试覆盖

单元测试新增 27 项，覆盖：

- 空库与多批 80 张图片备份、完整 ZIP、图片二进制哈希。
- 正文、感悟、标签、收藏、草稿、采集回链、设置、已有分析项目恢复与目录重建。
- 稳定 ID 去重，图片和草稿入口冲突、关联分组跳过、本地保留。
- 笔记与未提交草稿共享逻辑 ID，仅存在一侧时也防止合并到本地另一份无关内容。
- 完整替换确认，模拟空间不足、部分写入后取消，七个业务表与索引整体回滚，可重试。
- 损坏 CRC / SHA、不兼容版本、缺失图片/关联、重复 ID、恶意 URL、超范围时间拒绝。
- 路径穿越、未知路径、重名、压缩/加密条目、解压尺寸欺骗、截断与单项超限拒绝。
- 大像素图片头及尺寸不符拒绝；凭据白名单与脱敏，原始 URL 文本保留。
- v1 真实数据库经现有迁移链导出恢复，以及 schema 1 格式元数据迁移，感悟与时间不变。
- 校验阶段取消或暂存空间不足时主库不变、临时数据清理，无 fetch 调用。

真实 Chrome 测试新增 7 项，覆盖空库下载/预览/用量、完整多图与草稿往返、二次确认取消与替换、另一设置页不清理活跃预览、管理页自动刷新、浏览器重启后保留、合并去重与冲突提示、损坏文件及未来版本拒绝、真实 IndexedDB 配额异常和 abort 回滚、恢复中关闭 Chrome 进程后回滚与暂存清理、128 张原图分批备份恢复。全流程使用独立临时配置和合成数据，不使用个人登录态或私人笔记。

恢复预览布局已目视检查。生成的 ZIP 另使用 Python 3.12 标准 `zipfile` 独立验证 CRC，按清单计算 SHA-256，与应用内读取器分开验证。测试 ZIP、数据库、图片、trace 和性能 JSON 均留在被忽略的测试目录，不上传 GitHub。

## 已知边界

- 备份不加密，无自动云备份、增量备份或分卷。仅接受 IdeaClip 格式 v1 的安全 ZIP 配置，不导入任意通用 ZIP；未来 schema 版本明确拒绝。
- ID 冲突采用保留本地并跳过关联分组，可能跳过多条；界面报告数量，不自动覆盖或重新编号。可先备份本地，再明确选择完整替换恢复整个备份版本。
- 常见凭据与敏感 URL 参数脱敏，浏览器标签 ID 清空，因此这些字段不逐字恢复；不承诺识别笔记或图片中任意人为写法的秘密。
- 单次合成数据性能不代表上限容量、所有硬件或长时间压力测试。Edge、全面无障碍、512 MiB 上限的实机压力与额外并发编辑压力尚未验收。
- X 真实样本仍未能读取正文，微信仍缺真实文章验收；本阶段未改变原采集适配结论。
