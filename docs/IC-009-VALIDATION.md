# IC-009：AI Skills 商业分析模板验收

日期：2026-11-06。基线 `6425ba93fc27fd4b9c1b4909fad094a0d66619f7`。仅实现受限分析模板，保留原 AIEngine、队列、费用与来源门禁；不开发联网研究、侧边栏或项目孵化。开发前 main 已更新，已阅读开发约定、AI 引擎、调研及路线图，并用已有 CodeGraph 检查调用与数据关系。

## 五种内置模板

| 模板 / 稳定 ID | 输出结构与用途 |
| --- | --- |
| 商业模式拆解 / `builtin-business` | 保留原 15 栏 v1：创意、用户、痛点、定位、商业模式、收益、获客、优势、成本、复制、风险、7/30/90 天计划与调查问题 |
| 低成本创业可行性评估 / `builtin-lean` | 资源约束、最小可售交付、成本/现金流假设、需求实验、停止条件、未知项 |
| 竞争对手分析 / `builtin-competitor` | 已知产品证据、细分用户任务、竞争/替代假设、差异比较、壁垒/反击风险、调查缺口；只基于输入，不联网找竞品 |
| Codex 项目开发方案 / `builtin-codex` | 需求与验收、架构/模型、实施任务、测试交付、安全风险、自包含中文开发指令；只复制文本，不执行 |
| 7/30/90 天执行计划 / `builtin-plan` | 起点假设、7 天需求验证、30 天试点、90 天复盘扩展、依赖风险、阶段决策门槛 |

每份定义含 ID、版本、名称、描述、适用场景、输入要求、提示词、栏目描述、最大输出和展示方式；由受限栏目生成可查看的 JSON Schema。五者的必需 key、分析要求和展示内容不同，不是换标题。内置版本为 1.0.0，保持只读；可复制为独立自定义模板。

## 使用与版本行为

- 设置页可新建、编辑、复制、启停、设置默认、导出和导入；栏目名称与分析要求直接填写，不要求用户写 JSON。自定义删除二次确认，历史报告保留。
- 模板本体最多 24 KiB，单模板文件最多 32 KiB，提示 6000 字符；只允许 `{{title}}`、`{{content}}`、`{{body}}`、`{{url}}` 共最多 20 个占位符，一次 JSON 字符串转义替换，不递归、不解释表达式。
- 栏目 2–15 个、每栏 1–8 条，条目 text≤3000 / evidence≤1000 Unicode 字符。模板输出上限 256–8192 Token，实际取模板与服务商配置较小值。模板/Schema/展开后文本均计入费用；过大输入明确失败，不静默截断。
- 分析页选择模板后，预览显示版本、最终 system/user 文本、资料范围、费用和输出上限；选择、设置和预览不创建模型请求，只有既有单次确认或有效自动授权才能发送。
- 手动预览冻结模板完整定义，后续修改/删除/停用使旧预览失效。保存按编辑时版本做事务比较；并发冲突不覆盖新数据，输入保留，可主动重新读取模板。
- 自动授权绑定默认模板 ID/版本/规范化完整定义和本机偏好版本；任何模板管理写入轮换偏好版本、取消客户端请求并暂停等待队列。用户需重新确认自动模式；旧任务模板不同则保持暂停，不自动换版本，不重复执行可能已计费任务。
- 同一笔记可保留不同模板的多个历史报告；报告保存模板快照、模型、时间和分析时来源 URL。来源摘录区分事实陈述、推测和假设，可打开原网页、复制、导出 Markdown；Codex 报告另可复制完整中文开发指令。来源页面可能变化，引用不是事实核验。

## 安全与兼容

模板提示、栏目标签/说明、场景和用户资料只在 user 数据中。system 由固定安全前缀及应用生成的受限 Schema 构成；拒绝未知角色、tools、脚本、远程 `$ref` 等字段，不进行动态编译或 eval。任意模板不能改变 transport 的端点、权限、重定向策略、总开关或预算。Prompt 注入文本不会获得工具执行权；模型语义上仍可能出错，不声称完全防止一切误导输出。

每份报告必须通过固定栏目/类型/长度/额外字段和逐字 evidence 检查。v1 继续使用原 Ajv 独立验证器；其余受限 Schema 由逐字段验证器检查，单元测试用 Ajv 编译同一 Schema 对照。模板字段中的当前凭据在请求预览和报告快照中移除，导出模板及 ZIP 做常见凭据脱敏；无法识别所有人为秘密，不应把密钥写进模板。日志不新增正文、完整模板、凭据或服务商错误内容。

Dexie schema v9 只新增 `aiTemplates` / `skillPreferences`；旧笔记、原图、采集、草稿、报告、任务和预算保持。旧自动任务不补写模板授权。旧纯文本与 15 栏报告照常显示，已保存的快照不依赖模板仍存在。

ZIP v2 新增第八业务表 aiTemplates，保留 v1/schema1–8 读取，整体支持 schema1–9。自定义模板与报告先校验再脱敏；新写入的恢复模板停用（合并时跳过的本地重复记录保留原状态），恢复事务轮换本机偏好版本，不能迁移执行授权。默认选择保留为本机设置，指向已删除/停用模板时需重新选择；不静默回退执行。单模板 JSON 导入创建新 ID/新版本的停用副本，不覆盖本地同 ID。配置、凭据、自动策略、队列、预算和本机偏好版本继续不导出。

本轮独立实现，未复制第三方模板、业务模块或受限许可代码；未新增依赖或 Chrome 权限，package.json、锁文件及 Manifest 无变更。

## 遗留与未验收

- 未调用真实付费模型，不能证明所有模型都遵循不同 Schema、提示语义或生成高质量商业判断；格式不合格会明确失败，不自动重试。
- 原生权限和普通安装跨重启、Edge、真实 X/微信、全面无障碍及长期压力沿用既有验收边界；本轮没有宣称新通过。
- 默认模板是本机偏好，备份恢复不携带本机选择/授权版本；恢复的模板需检查后启用并重新确认自动模式。
- 模板输入要求是说明，不是自动补齐资料；竞品报告不联网调查，Codex 指令不创建任务或执行代码。
- 模板表单未保存修改仍留在当前页面，但关闭该设置页不会像笔记编辑器一样自动保留模板草稿，应先点保存。
- 不包含联网深度研究、AI 侧边栏、项目孵化或任意代码型 Skills。
