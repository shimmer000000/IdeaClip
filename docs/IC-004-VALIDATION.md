# IC-004 管理中心验收

本阶段只开发管理中心，沿用截图、正文采集、统一编辑和本地数据库。没有新增浏览器权限、备份恢复或 AI 请求。

## 自动化验证

环境：Windows、本机 Chrome 156、独立临时浏览器配置，不使用个人登录态和真实笔记。

执行命令：

```sh
npm test
npm run build
npm run test
npm run test:e2e
```

2026-11-06 最终结果：两次单元测试均为 **75/75**，Chrome 浏览器测试 **24/24**（包含 IC-001 至 IC-003 全部 18 项回归），TypeScript、生产构建、Manifest V3 / 页面入口 / 资源引用 / 网络限制检查全部通过。生产依赖审计 `npm audit --omit=dev` 为 0 个漏洞。

单元测试覆盖组合搜索、六种搜索范围、日期边界、排序分页、缓存与取消查询、批量操作及未提交编辑保护、部分失败与事务回滚、删除确认与引用保护、v4 → v5 迁移保留笔记、草稿、原图、采集与设置。既有截图、采集、编辑和 AI 门禁用例继续执行。

新增 Chrome 测试覆盖卡片与列表、分页、缩略图尺寸、大图与多图切换、完整笔记、原网页链接、组合筛选、草稿与收藏、批量分类标签收藏、未提交编辑跳过、删除二次确认、图片与采集保留、进程关闭重启后的数据保留，以及 1 万条数据检索。卡片布局已目视检查。

## 性能方法

`tests/browser/library.spec.ts` 的“10000”用例生成 10000 条合成笔记，每条约 2200 字符采集正文，引用 48 张本地合成原图（1280 × 800，包含一张约 1 MB 的噪声图）。默认页面 24 条。重新加载管理页测量轻量目录首屏，搜索唯一关键词测量完整文本索引检索；搜索耗时包含 250 毫秒防抖。

同时记录 16 毫秒定时器的实际间隔作为主线程响应观察值，记录原图读取次数、峰值并发及 object URL 创建与释放。搜索结果刻意不包含截图，用来验证列表离开后 URL 全部释放。测试阈值为首屏与搜索各小于 5 秒、定时器间隔 P95 小于 250 毫秒、原图读取峰值不超过 2，页面仅渲染 24 条卡片。

最终完整测试套件中记录的结果：

| 指标 | 结果 |
| --- | ---: |
| 轻量目录首屏 | 317 ms |
| 全文搜索（包含防抖） | 893 ms |
| 主线程定时器间隔 P95 / 最大值 | 23.1 / 41.5 ms |
| 原图读取总数 / 峰值并发 | 3 / 2 |
| 筛选到无截图结果后未释放的 object URL | 0 |
| 当前页 DOM 笔记数量 | 24 |

测量值写入被忽略的 `test-results/**/performance.json`，测试截图、原图及数据库不会上传仓库。辅助目录只保留元信息与感悟摘要，文本索引在 Worker 中每批读取 64 条，目录每批 256 条；该测试没有一次性读取全部原图。

该测试是本机单次合成数据结果，定时器间隔不是帧率，也不代表所有设备或任意数据量下的性能保证。缩略图缓存增加本地占用，首次迁移需要空间构建辅助索引。

## 安全与范围

- schema v5 只新增辅助表，旧笔记感悟与正文保持独立，不删除原数据。
- 单条操作原子提交；批量操作允许逐条成功或失败，明确报告结果。非删除操作跳过有未提交编辑的笔记，避免覆盖输入。
- 批量删除需确认；删除笔记保留原始截图和采集记录，不回收仍有引用的原图。
- 预览使用纯文本和受限 HTTP/HTTPS 链接，图片只来自本地数据库；AI 默认关闭，保留原有禁止外部连接的 CSP。
- 尚未验收 Edge、全面无障碍、超过 1 万条数据或其他硬件。X 真实样本仍未读到正文，微信真实文章未验收；沿用 IC-002 的限制，不把模拟页面通过视作平台真实通过。
