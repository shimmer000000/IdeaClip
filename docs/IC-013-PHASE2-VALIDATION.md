## 已实现范围

已保存研究中提供“联网研究”。支持竞争对手、商业模式、产品定价、GitHub、需求验证和自定义问题。保存代理配置只申请指定代理域名可选权限，不探测接口；联网默认关闭。打开/启用入口不自动执行，必须预览问题、全部搜索词/URL、允许域名、数量、单价和本次预留后单次确认。

ResearchAdapter为可替换接口；默认Research Proxy v1，浏览器仅向配置的完整端点fetch，不读取其他标签/历史，也不尝试直接跨域抓所有网站。参考自有代理需要Node24+，可显式运行，内置Brave Web Search、公开HTTPS HTML/纯文本和GitHub公开元数据；不提供AI模型代理。完整协议、环境变量与安全边界见 [RESEARCH-PROXY.md](RESEARCH-PROXY.md)。真实服务商未调用。

联网资料保存来源ID、问题、URL、标题、公开时间（可取时）、实际采集时间、来源类型、正文、逐字摘录、读取状态、SHA-256。没有公开日期保持未知；摘要不是全文，截短标部分，访问失败/不可读不凑正文。HTML清除脚本、资源、事件、表单、隐藏/导航区域后Readability提取，不挂入活动网页。来源哈希不证明事实，作者说法、模型推断与假设分开显示。

研究账本按USD/UTC每日持久预留，整批预检、逐请求事务检查；最多3次搜索、5页，每次最多5条结果，正文100–30000字符，最多500条联网资料/研究。用户价格是估算，不能保证实际账单。暂停、取消、关闭、配置变化、权限撤销和恢复停止新请求；请求发出位置提前持久化，失败/未知费用不退回、不自动重试；重启只标记中断，明确未发部分须新的计划确认。任务/资料/报告历史按时间分页。

AI综合通过原AIEngine，选择1～10份实际资料，独立展示模型/服务商/精确文本/Token与费用并确认，不含截图、不联网、不进入自动队列。固定8栏Schema；原文/作者主张/AI推断/假设分开；引用须对应当前研究真实ID、逐字quote，未知URL、伪造来源及凭据回显拒绝。研究/资料全快照发送前、预算事务和返回后复查。报告独立保存历史、复制与Markdown；付费结果写入失败可重试保存而不再次请求模型。来源引用验证不等于自动事实核实或语义蕴含证明。

## 代理安全检查

- 客户端按配置域名/源URL范围筛选，服务端再作精确白名单检查；任一未授权源或敏感/凭据URL拒绝。前端仅允许公开HTTPS代理域名或用户明确配置的本机HTTP代理。
- 服务端检查所有DNS回答，阻断IPv4/IPv6私网、环回、链路本地、保留/文档、映射/协议转换和作用域地址；固定本次连接IP并保留TLS域名校验，不作第二次可重绑定解析。任何3xx拒绝，不跟随Location。
- 代理Token仅发给配置端点；Brave Key只发固定Brave官方端点，不转发至网页；GitHub请求无用户Token。来源不带Cookie、Referrer、浏览器登录态，无请求数据日志，密钥回显拒绝。
- 不执行网页JS/命令，不绕过登录、付费墙、验证码或访问控制。源请求2 MiB、请求体/头和20秒代理超时有界。CORS仅配置扩展Origin，Bearer独立访问密钥必需。
- 参考代理默认仅监听loopback。服务端50次/UTC日搜索计数在内存，重启会重置，不是服务商硬费用保证；客户端账本持久化但仍是本机估算，不替代服务商/服务端账户配额。
