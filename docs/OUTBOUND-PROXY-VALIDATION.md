## 实现与安全边界

- 新增`tools/research-outbound.ts`，默认direct；connect仅支持显式字面loopback HTTP端点、`auth:none`、`certificatePolicy:node-default`、`approved:true`。其他认证/远程/HTTPS代理/SOCKS、未批准、URL凭据/路径/查询或未知字段明确拒绝，不自动套用系统/环境代理。当前不提供远程或认证代理，避免在本轮引入额外认证与代理端DNS边界。
- 目标仍由原代理固定Brave/GitHub或精确来源白名单生成，先校验全部DNS回答。任何私网、保留、IPv4/IPv6家族不匹配均在连接前拒绝。选定首个已校验地址后只发送数字`IP:443`（IPv6加方括号）和同样的Host，不二次解析目标、不重试其他IP、不回退直连/域名CONNECT。
- CONNECT请求不带Brave Key、代理Token、Cookie、Referrer或Proxy-Authorization。200之前不启动目标TLS，额外隧道字节/3xx/407拒绝。隧道内按原始目标域名SNI及Node默认可信库严格验证，`rejectUnauthorized:true`、HTTP/1.1 ALPN；不关闭主机名检查或添加用户CA。严格TLS成功后才创建一次性HTTPS Agent，在该已验证socket里发送原站Host、路径及原站需要的头。公共网页请求不转发搜索Key。
- Node当前默认可信库不等于自动导入所有Windows企业根证书；如用户自行配置额外CA，那是须审查的进程信任环境。本功能不安装CA或改变系统策略。证书不可信或域名不符时，不发送上游应用层凭据。
- 客户端只能保证发给代理的CONNECT authority是校验后的数字IP，无法独立证明代理内部实际路由。**必须确认受信任代理遵守数字IP转发，不通过SNI/sniffing/规则重写目的地址**。CONNECT/TLS成功不是该性质的证明。若无法确认或代理要求主机名才能连接，不批准生产模式；不以放宽SSRF/TLS换取可用性。代理可见目标IP、SNI和流量时序，不能信任恶意代理/中间人CA。
- 可行替代：保留直连，由用户/网络管理员处理可信DNS及出站路径；或另行审计一个服务端执行公共DNS全地址校验、固定IP连接、拒绝私网/重定向且有访问控制的受控研究网关。未在本轮自动部署或将Key交给陌生代理。
- 原20秒生产代理/30秒默认客户端、免费诊断10秒独立上限与取消规则保持。失败销毁CONNECT/TLS socket，不降级、不重发；已发送结果未知仍保留预算。新增OUTBOUND_PROXY_UNREACHABLE、CONNECT_REJECTED、CONNECT_PROTOCOL_INVALID以及outbound/connect阶段，不输出原始错误或认证挑战正文。

## 配置与诊断体验

Windows仍双击`windows/Start-Research.cmd`。新增网络模式下拉框、空端点输入、未勾选审查框；默认直连、不自动读取系统代理作为配置。选connect后才启用输入/审查框，模式/地址改变清除确认；运行中禁改，停止后清除确认；每次新开窗口默认直连。进程内配置经原匿名stdin传入托管Node，独立诊断也只从stdin接收受限outbound对象，不传Key或把地址/批准放入argv、环境或文件。

免费DNS/TCP/TLS/环境诊断沿用本次显式模式，浏览器报告显示直连或HTTP CONNECT数字IP路径、代理连接/隧道阶段。扩展不能通过网页请求改出站代理，也不保存该执行资格。报告继续按字段白名单重建，不包含端点、凭据、笔记或原始HTTP；Brave认证/额度始终标未测试/未验证。

本轮没有数据库迁移；模式只在本地服务窗口/子进程内存中，不进入ZIP或浏览器预算。恢复备份、重启浏览器/服务都不能授予代理或付费执行权；原首次失败记录与0.005 USD预留不清除。服务进程内搜索尝试计数重启会归零的原限制不变，不能拿它重置扩展持久预算或当服务商账单。

操作：

1. 旧服务若在运行，由用户点击安全停止并关闭旧窗口，不按端口/进程名强杀。打开更新后的Start-Research.cmd。
2. 保持Brave Key留空即可做免费诊断。只有确认自己代理的IP转发行为、无认证和Node默认TLS信任策略后，选择受信任模式、手填端点并勾选审查。
3. 主动点击检查DNS及TCP/TLS。错误先看阶段，407/不支持IP/证书错误不降级；无需开启搜索或AI，也不会新增费用。
4. 如需研究中心显示同一路径，按原流程填写扩展ID/本地代理Token/来源白名单启动服务，保存扩展的代理配置；重新加载原扩展即可，不卸载或清空数据。浏览器的免费诊断只访问已授权本地服务。
5. 实际搜索仍须新的逐次范围/次数/单价/预算确认；当前只批准一次免费握手，没有批准再次搜索。下次建议只预览1次原公开关键词与精确来源，明确本次预留及未知费用风险，等待用户批准后才执行。DeepSeek也须另行单次批准。
