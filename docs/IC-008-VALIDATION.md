## 单元测试

- 默认手动、自动关闭、全局关闭、草稿保存、浏览辅助未确认不入队；已授权的主动保存入队，暂停期间只创建暂停任务。
- 笔记/任务同事务、同 revision 去重、重复保存无新任务、队列配额写入失败整体回滚且草稿输入保留。
- 明确范围/预算确认、金额和域名校验、精确白名单、含子域黑名单优先、银行/邮件/登录/敏感查询等拦截；本地五类候选规则。
- 自动任务复用 15 栏 Schema、报告和预算；请求零图片、拒绝重定向、不带 cookies。两执行者的任务锁防止重复请求。
- revision、原始正文、未提交编辑、删除使快照失效；暂停、总开关、配置/凭据/会话、权限、单次费用及每日预算门禁。
- 超时仅一次请求，保留未知费用；单个取消、暂停、全局关闭、停用自动模式、更新持续授权取消运行请求并暂停后续队列。
- 用量账本缺失不能视作免费；失败/已尝试任务不能通过恢复自动重发。新的手动预览、重复计费确认后才可重试；报告保存重试不产生模型请求。
- 先以两项失败测试复现“报告已保存但完成状态写入失败”和“取消/完成竞态”问题，再修复为查找已有请求 ID 的报告并关联完成；手动预览和执行前也先检查报告，避免为了状态不一致重复付费。修复后全量单元与相关浏览器检查通过。
- 浏览器重启和同会话执行页中断：未知运行任务失败并暂停后续；找到既有报告恢复完成；只人工恢复未发送、快照仍有效的暂停任务。
- 浏览辅助网站权限撤销后，即使服务商权限仍有效也不能执行/恢复；无客户端 Key 的安全代理保持兼容。
- schema6 → 7 保留旧笔记、原图 Blob、报告、配置和预算，新增表空且不默认授权。报告 ZIP 往返兼容，队列/策略/账本不导出，恢复前暂停并保留本设备任务和预算。

## Chrome 浏览器测试

1. 默认模式/总开关、配置不请求、草稿不分析；实际编辑器主动保存后服务 worker 打开执行页，生成 15 栏报告，重复保存不产生新请求。
2. 暂停保存、人工恢复、两个执行页互斥、取消单个未发任务和取消全部等待。
3. 运行请求取消、后续任务暂停；失败/取消重试弹窗必须勾选普通费用确认和重复计费确认，才产生新的 Mock 请求。
4. 全局关闭取消当前请求、暂停等待任务，关闭状态新保存仍正常且不入队。
5. 原始数据修改后旧快照拒绝、敏感邮箱 URL 拦截、权限撤销无请求、预算耗尽暂停。
6. 真实 fetch 超时、失败原因和费用记录，无自动重试，恢复未发任务不能重发此项。
7. 真正关闭 Chrome 并用同一独立配置启动：任务和报告数据保留，中断运行标未知费用失败，等待转暂停；恢复只发送另一条未发任务。
8. 白名单本地建议无 AI 请求、无自动笔记保存；通过真实扩展按钮取得 activeTab，在真实隔离内容脚本世界注入构建后的 `assist.js`，用 CDP 定位 closed Shadow DOM 按钮并执行可信鼠标点击，进入编辑草稿后勾选并保存才入队。
9. 密码表单不显示候选；关闭浏览辅助移除已经注入的提示，全程无 AI 请求。

原生权限弹窗是 Mock 边界，记录并检查仅授权 `http://127.0.0.1/*`。浏览辅助测试还 Mock worker 的网站权限查询与动态注册 API，校验注册参数为精确主机、主框架、指定脚本；实际内容脚本通过 Chrome scripting + 真实 activeTab 授权执行。**未把该结果标记为原生用户授予/撤销或动态自动注入的完整流程已通过**。运行时消息、Web Locks、IndexedDB、会话/本地凭据隔离、请求、取消、页面点击和 Chrome 重启为真实浏览器行为。

原有 39 项 Chrome 回归全部通过，包括区域截图缩放/DPR、正文采集本地样本、组合编辑和重启持久化、卡片/列表与批量管理、完整 ZIP 原图往返和事务回滚、手动 AI 确认/图像/取消/预算/Schema/凭据回显和重定向拦截。

本轮原有性能回归实测：10000 条模拟笔记首屏约 342ms、正文搜索约 887ms、心跳 p95 约 20.7ms；128 张原图 / 240 条笔记备份约 46.1 MB，导出约 933ms、校验约 3968ms、恢复约 310ms。这是本机结果，不保证其他设备或大于测试规模的数据性能。

## 安全和数据边界

- 不新增安装权限，继续仅 `activeTab` / `scripting` / `storage`，没有 `tabs`、`history` 或安装时全站 host 权限。动态脚本只匹配用户授权白名单，后台仅查本扩展执行页，不轮询全部标签页。
- 总开关与自动开关默认关闭。保存模式/浏览候选不发模型探测请求，自动发送从不包含截图；AI 只走原 `AIEngine` 门禁与 transport。
- Key 继续仅 Chrome session / 显式长期 local，TRUSTED_CONTEXTS；不存 Dexie、VITE_*、队列、日志、报告或 ZIP。自定义端点绑定完整 URL，拒绝重定向、cookie/referrer，保留安全代理接口。
- 每个任务执行前、预留事务内、发送前及响应后复查授权、快照和成本。未知费用不自动退款/重发，客户端取消不保证服务商停止计费。
- 自动授权和执行状态不迁移；备份恢复暂停队列并保留本机账本，不能通过导入备份授权新的自动请求。

## 限制与未验收

- 自动执行依赖保持打开的任务中心标签页；并非操作系统后台守护进程。关闭后不会承诺持续执行，重启需人工核对恢复。
- 本地敏感识别和商业候选规则可能误判/漏判，不替代用户选择公开白名单、主动排除私人域名；输入表单值不读取。端口失联停止提示，重载页面后重检授权。
- 未做真实付费调用、OpenAI/DeepSeek 实际模型验证、原生权限弹窗/动态注册全流程、Edge 专项、全面无障碍或长期无人值守压力验收。
- 真实 X 与微信公众号仍沿用既有验收限制；本次仅本地可控页面验证浏览辅助，不将不可访问页面标为通过。
- 不包含自动上传截图、联网研究、浏览历史收集、全标签页扫描、自动重试或项目孵化。
