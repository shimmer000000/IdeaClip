# IdeaClip 路线图

## 阶段 0：项目初始化

已完成并验证：

- [x] React + TypeScript + Vite 工程和三个 HTML 构建入口。
- [x] Manifest V3 清单、最小权限及本地资源构建检查。
- [x] Dexie schema v1 与笔记 CRUD、开关持久化的基础单元测试。
- [x] AI 默认关闭与未接入门禁；测试确认不调用 fetch。
- [x] 敏感数据忽略规则、README 与开发约定。

已实现，待浏览器验收：

- [ ] Chromium / Edge 加载扩展，检查弹窗、笔记管理和设置页面。
- [ ] 在真实网页中读取标题和链接，并验证受限页面提示。
- [ ] 通过 UI 验证新建、编辑、删除、搜索、标签和状态筛选。
- [ ] 验证浏览器重启后数据保留，以及多个页面共享开关。
- [ ] 无障碍、错误恢复、响应式页面检查。

## 后续阶段（等待指令）

1. 收藏增强：选区采集、正文提取、重复链接策略、数据导出与恢复。
2. AI 商业分析：供应商适配、密钥安全方案、明确同意后发送数据、结构化分析与费用提示。
3. 项目孵化：灵感关联、商业假设、验证任务、里程碑与项目看板。

当前不包含上述后续功能，也不将预留表或设置偏好视为 AI 分析和项目孵化已完成。
