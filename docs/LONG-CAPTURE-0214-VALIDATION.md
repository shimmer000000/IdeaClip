# 0.2.14 网页长截图验收

日期：2026-11-10。基线：96ffb73c5659fb0ed9cf142b485d60f7d494ca0b。开始工作区干净，main与远程一致。

## 操作与实现

- 插件弹窗、现有截图预览和笔记编辑均新增“截取长图”（预览页为“重新截取长图”）。仅用户主动触发当前授权网页，不新增浏览器权限/依赖，不读取其他标签页、表单值或调用AI。
- 使用生产`chrome.tabs.captureVisibleTab`逐屏截图，串行间隔至少600ms，实际位图比例拼接；不是使用CDP整页截图实现产品功能。API权限及调用限额参考[Chrome官方Tabs文档](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab)。
- 固定isolated-world控制函数只暂时改变滚动位置、动画/滚动样式和fixed/sticky元素的visibility；不执行网页内容。Esc、滚轮、鼠标点击、切换标签、导航、失去页面可见性会中止。finally恢复原位置/样式，90秒页面看门狗兜底；网页关闭或导航不能承诺恢复旧页面。
- 采用实际visualViewport高度处理非整数浏览器缩放；相邻屏保留1 CSS像素安全重叠，只画尚未覆盖区间，避免底部重复及缩放量化接缝；输出尺寸向下取整，保持像素上限。逐帧解码并释放位图，只保留有上限的合成画布。
- 结束后压缩为WebP，预览/下载、IndexedDB Blob保存、笔记多图关联沿用已有实现；不使用临时object URL作为永久地址。压缩或保存失败明确报错，旧图不删除。

## 限制与安全边界

- 页面最多20000 CSS像素、40屏/帧；输出宽≤1600、高≤24000、总像素≤3200万、Blob≤6 MiB。超限拒绝，不静默裁掉剩余内容；普通可见/区域截图仍是原2560长边/2 MiB规则。
- 当前支持普通纵向主文档；横向溢出、主要内容在独立滚动容器中、复杂DOM超过20000节点会拒绝。无限滚动和懒加载造成高度变化时终止，等待加载完成后再截或分段截取。
- fixed/sticky悬浮内容不收入长图，避免重复遮挡。实时视频、内容替换和动画可能造成视觉差异；尺寸稳定不等于内容绝对静止或事实完整，需人工核对。滚动可能触发网页自身的懒加载；插件没有额外抓取/搜索/上传接口。
- 每帧复查活动标签、原URL、缩放、滚动、文档尺寸；取消/变化/权限失败不保存半成品，不会截取切换后的其他网页。新图不自动发送给AI。
- Dexie表/索引及数据库版本不变，仅Screenshot.kind增加full；旧记录保留。ZIP v6允许full并保持原图片完整性/恢复事务校验；旧备份仍可恢复，含full的新备份需0.2.14或更新版，旧版遇未知类型会拒绝，不能声称向旧客户端兼容。
