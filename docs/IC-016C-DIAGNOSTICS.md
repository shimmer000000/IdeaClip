## 首次失败的观察与证据边界

用户报告：Windows服务启动、`127.0.0.1:8788/research`免费健康、白名单和联网开关正常；Brave订阅及Key已配置。用户首次确认关键词`site:obsidian.md Obsidian pricing`，1次搜索本地预留0.005 USD后失败，显示超时/取消，无结果保存。用户当时看到Brave后台请求/错误/已用额度均为0。

这些是历史观察，不足以证明从未抵达Brave；健康只证明本地端点当时可达和认证成功，不检查上游。客户端在fetch前先事务记录sent、预留及next位置，因此“已发”也不证明代理search分支或Brave收到了HTTP请求。旧代理没有分阶段日志，无法补造那次DNS/TCP/TLS抓包或请求ID。原0.005预留保持不变，不自动退款或重试。

没有自动修改Windows DNS/代理/VPN/防火墙，没有添加hosts覆盖、硬编码生产IP、自动DoH回退、自动换地址或把Key交给其他网络代理。可选下一步由用户自行核对可信DNS/VPN分流或由网络管理员处理，再免费复测。若将来要新增显式出站代理，必须另行设计代理自身鉴权、CONNECT目的IP固定及DNS/重定向SSRF边界；本轮不盲目套用HTTP_PROXY绕过现有检查。

## 修复与新增诊断

1. `tools/research-diagnostics.ts`：固定主机、全DNS回答校验、TLS握手、原生网络错误安全分类和脱敏事件。`research-network-check.ts`是独立固定模式入口，Node24直接运行，不需要依赖、Key、搜索词或服务启动。
2. `research-proxy.ts`：保留全地址SSRF/TLS/IP固定/白名单/无重定向；search分支开始、DNS/安全/TCP/TLS与失败阶段进入最多30条内存事件。只保留阶段、毫秒和安全码，不输出URL/地址/查询/HTTP头/原始异常；health可只读最近20条。未知为UNKNOWN，不以异常message推断认证失败。
3. 新增鉴权后的`diagnose`操作，固定dns/tls/environment，不经过search、不读Brave Key、不增加计数或预算。健康仍不上游；诊断握手成功也只显示Brave认证未测试、额度未验证。浏览器解析报告按字段/码白名单重建，未知秘密字段不导出，凭据回显整份拒绝。
4. `ResearchAdapter`区分不可达、代理401/403、响应JSON/UTF8/结构不合法和服务端安全码；`OnlineResearch`将阶段保留到原任务reason，客户端超时/取消不再冒充认证。已发送结果未知记unknown，阶段明确失败记failed；所有预留保留，next位置和一次性确认不重置，不自动重试。
5. 搜索参数仍固定Brave Web Search、5条上限、safesearch strict，并组合本次精确来源域名。200合法空结果分为EMPTY和FILTERED；API失败/格式错误仍失败、不保存伪造来源。旧代理无状态字段仍显示无法区分的旧提示。
6. Windows窗口保留原启动/安全停止，新增五类按钮：本地代理、Brave DNS、Brave TCP/TLS、网络代理环境、主动导出诊断。独立诊断子进程只接收固定模式，不传配置/Key/URL，输出白名单事件及环境布尔值；Node版本/8788占用可读。仅导出用户主动选择路径的脱敏JSON，不写密钥配置。
7. 研究中心新增“网络诊断（免费）”，只用既有代理端点/会话授权；无权限零请求、撤销/配置变化取消、诊断可取消、报告主动导出。失败显示阶段、安全码、是否可能发送/计费、免费重测范围和下一步；原开关及账本保持。
8. DeepSeek仍由原AIEngine和Chat Completions协议执行，不重建引擎。补官方provider纯Mock的非思考/十二栏中文JSON、逐字引用、预算、usage、历史及Markdown；沿用已有保活空行/UTF8分块/429/Schema/来源ID回归。确认框显示UTC每日限额及动态剩余预留预算，发送前仍事务复查，不把估算当实际账单。研究8192是模板最大输出/验收建议，并非代码强制最低值。

## 错误码与费用含义

| 安全码 | 阶段/含义 | 发送/计费判断 |
| --- | --- | --- |
| PROXY_UNREACHABLE | 浏览器到本地代理不可达/连接断开 | 浏览器不能确定服务端是否处理，未知，不退款/重试。 |
| PROXY_AUTH_FAILED | 本地Origin/Bearer/权限或凭据校验 | 已知本地认证失败不发送上游；浏览器预检缺失也不请求。 |
| DNS_LOOKUP_FAILED / DNS_ADDRESS_BLOCKED | DNS失败 / 全地址公共IP检查拒绝 | 此阶段未发送搜索HTTP。 |
| TCP_CONNECT_FAILED | TCP建连失败 | 未发送HTTP搜索。 |
| TLS_HANDSHAKE_FAILED / TLS_CERTIFICATE_FAILED | 握手/证书拒绝 | 未发送HTTP搜索；不关闭证书验证。 |
| UPSTREAM_TIMEOUT | 代理上游超时，同时附已知dns/tcp/tls/http阶段 | DNS/TCP/TLS阶段未发送搜索HTTP；http阶段结果可能未知。 |
| CLIENT_TIMEOUT / REQUEST_CANCELLED | 浏览器时间上限 / 用户、权限或配置停止 | 无法由浏览器确认上游是否处理，保持未知。 |
| SEARCH_AUTH_FAILED | Brave401/403 | 已收到HTTP响应，可能占用请求统计；未读取上游错误正文。 |
| SEARCH_QUOTA_EXCEEDED | Brave402/429 | 可能额度/限速，实际账户为准。 |
| SEARCH_HTTP_ERROR | 其他非200HTTP（含5xx） | 不猜测凭据问题，不读服务商错误正文。 |
| SEARCH_RESPONSE_INVALID | 代理/上游JSON、UTF8或结构无效 | 不能当空成功；若已发，费用未知。 |
| SEARCH_RESULT_EMPTY / SEARCH_RESULT_FILTERED | 有效搜索0条 / 有结果但URL或白名单过滤后0条 | 任务可完成并明确提示；是一次实际搜索，仍记成功请求与预留，不扩域重试。 |
| UNKNOWN | 无足够阶段信息或旧代理安全拒绝 | 不猜测，不退款或重试。 |

新码不含敏感详情；旧search_auth/quota等显示仍兼容。DNS/阶段信息不是退款授权，也不是服务商账单证明。原0.005 USD是用户填写的本地保守预留，保留；账户赠送额度不是插件预算，不因它自动增加可请求次数。

## 超时和取消

生产代理总限仍20秒，默认浏览器30秒，保留安全错误传回余量。用户若把客户端设为1秒等短于代理的值，浏览器可先超时，显示CLIENT_TIMEOUT，不能保证收到服务端详细阶段。没有为“成功”无限延长请求。

Windows独立免费握手10秒总限；浏览器免费诊断25秒客户端上限，代理仍20秒。DNS挂起支持取消，连接/握手超时销毁socket，不发HTTP。用户取消、页面关闭、权限撤销均中止客户端，原未知费用规则不变。Node主动保留不重试第一个固定IP的设计，不因IPv6失败暗中发第二次搜索。
