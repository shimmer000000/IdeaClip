## 范围与结果

本阶段实现本地研究方案和人工资料管理，不将“深度研究”入口伪装成已联网调查。四种提纲根据研究名称通过本地规则生成，清楚标注不调用 AI、未分析正文或核验市场。用户可编辑全部提纲与资料。

- 已保存灵感编辑页/完整笔记、项目资料、已保存 AI 报告/对比报告及导航均提供入口。研究中心最近 30 条分页，关联选择最近 100 条并支持填写 ID；草稿或缺失来源不能新增关联。
- 研究名称、目标、研究问题、关键词、竞品清单、GitHub 核查清单、备注和资料可创建/修改/删除。资料包括公开 HTTP/HTTPS URL、标题、摘录、证据、备注及其关联来源。
- 原始事实（用户标注、未独立核验）、作者主张、AI 推测（手动记录）、待验证假设分别显示；事实要求摘录和证据。没有自动生成营收、市场规模或真假核验标签。
- 研究引用保存类型、ID、标题和来源时间；来源修改/缺失提示但不换绑或级联删除。删除研究不删除灵感、项目或报告。研究资料可选择关联本研究中的多个来源。
- 每次更改保存追加完整版本，相同内容保存不增加版本；历史只读、可作为新编辑保存，不覆盖旧版。支持按版本导出转义 Markdown。事务与 revision 校验阻止旧窗口覆盖；失败输入保留，离开未保存编辑前提醒。
- 单研究最多50个版本、100条资料、100个关联、2 MiB；字段和数量有界，超限拒绝，不静默删除历史。未提交研究没有自动草稿恢复，须主动保存。

## 数据与安全

Dexie v12 仅增 researchPlans。原笔记、Blob、采集、项目、模板、报告、任务、预算和设置不重建、不清空。研究版本快照为唯一权威数据；保存和删除使用事务、稳定 ID 和预期 revision。

ZIP v4 增研究表的路径与计数，包含全部历史、资料和软引用；继续读 v1–v3/schema≤12。研究逐字段白名单构造，全部版本的常见凭据文本和敏感 URL 参数脱敏；未知授权/执行字段不进入备份。原隔离校验、CRC32/SHA-256、逐条结构验证、冲突跳过、完整替换二次确认及事务回滚继续复用。API Key、配置、预算和队列执行授权不导出，恢复不赋予 AI 权限。

研究模块不实例化 AIEngine、不读取凭据、不调用 transport、不进入自动队列。AI 总开关、一次性确认、端点/权限/预算/取消/重定向防护保持原有实现并通过回归。公开 URL 仅做语法、协议、用户名密码、本机和常见私网字面地址检查，不作 DNS/联网访问，不证明页面公开可访问。主动点击打开来源才导航，不预取、不抓远程图片。来源内容、HTML 和命令仅作为纯文本保存和展示，导出 Markdown 转义；不使用 eval、工具调用或脚本执行。
