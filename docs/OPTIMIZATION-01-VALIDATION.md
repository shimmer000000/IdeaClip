# 开源调研后第一轮优化验收

日期：2026-11-06。基线：`9d9670e9133bef4dd11d284b2e0fb8fae78d9676`。范围为 IC-008 安全验收、正文质量及来源段落、自动分析质量门禁；不包含侧边栏、联网研究或项目孵化。

## 实现与数据兼容

- 保留现有 Readability、GitHub/微信分支和按当前 URL 帖子 ID 定位 X 主帖的实现。独立实现质量模块，没有复制第三方业务代码，没有新增依赖、权限或付费服务。
- 普通正文需至少 160 个非空白字符、2 个至少 8 字符的有效段落；X 主帖使用至少 12 个非空白字符的短帖策略。链接文本占比大于 45%、未展开/截断、未知 URL 会降低为部分，无正文为不可读取。隐藏/输入区域只计清理提示，不因为已正确排除而惩罚正文。评分是启发式，不是准确率或事实可信度。
- 采集和编辑页分开展示质量、来源匹配和原采集完整性提示。“完整”仅为当前可读范围；X 线程、未加载内容、登录限制仍不视作完整网页。用户可以保存和手动修改任何可保存的正文，不把补充内容伪称网页原文。
- 段落保存字符 offset、截取 quote、来源 URL 和定位指纹；最多 512 段，界面每次展示 12 段。可见 DOM 唯一匹配时附位置线索，未匹配或内容/URL 变化时明确说明。原网页查找使用文本片段，页面改变或浏览器不支持时可能失败，以保存快照为准；不执行保存的 DOM 选择器，不发起网络核验。
- 自动任务必须有与笔记全文和 URL 一致、质量完整、来源为网页且未经修改的关联采集。低质量、缺少来源、手动补充、旧采集和恢复数据正常保存，保持待核对/暂停，不能通过“恢复任务”绕过。用户可在原手动 AI 页逐次预览确认；自动模式不发送截图。
- 在入队、恢复、执行前以及原引擎预留/发送/返回的授权检查中复核质量。仍沿用 SHA-256 任务快照、费用锁、域名/凭据版本、敏感来源和每日预算；定位指纹不是安全签名。
- Dexie schema v8 仅增加可选字段，不删除、重置或回填旧数据为“通过”。ZIP 仍为七表白名单，接受 schema 1–8；质量及段落从脱敏正文重新构造，来源强制标记 backup，不能携带自动发送资格。任务、授权、配置和预算仍不迁移。

Windows / Chrome 156；构建产物加载到独立测试配置，测试使用合成笔记、图片和凭据，模型请求只连接本机 Mock API。

| 命令 | 实际结果 |
| --- | --- |
| `npm test` | 13 个文件、224 项通过 |
| `npm run build` | TypeScript、三组 Vite 构建、Manifest/资源/CSP/网络限制检查通过 |
| `npm run test` | 224 项再次通过 |
| `npm run test:e2e` | 50 项真实 Chrome 自动化通过，约 1.9 分钟 |
| 质量与队列专项 | 11 项 Chrome 测试通过（包含在 50 项中） |
| 原生权限续验 | 同一原生测试配置重启续验 1 项通过；只覆盖续验部分，见下一节 |

较基线新增 31 项单元和 2 项普通浏览器测试。覆盖普通文章、工具介绍、GitHub、X 精确主帖及未展开内容，空/短/链接密集正文、隐藏及输入区域、contenteditable 继承与 plaintext-only/false 大小写、特殊字符及有界段落、来源/内容修改失效、损坏指标、质量门禁恢复与执行复查、schema7 → 8 旧数据保留，以及质量元数据 ZIP 往返。原截图、笔记事务/草稿、管理中心、备份回滚及手动 AI 回归全部通过。

浏览器实际采集本地公开产品页并显示质量、来源及段落链接；请求不含隐藏测试内容、输入框内容或截图。短正文及手动补充可保存、重载保持，但不产生自动请求。质量区域截图已目视检查，无重叠或溢出；截图与 trace 不上传。

## 真实 Chrome 原生权限：分段验收

普通 `test:e2e` 套件仍 Mock 原生权限提示，浏览辅助场景还 Mock 注册边界；不能用它证明原生授予流程。因此新增独立交互脚本 `npm run test:native`，原生 permissions 和动态脚本注册/注入不做替换，模型服务仍为本机 Mock。

电脑操作工具因无法可靠识别 Chrome URL 停止后，没有继续用桌面工具操作。由用户在独立的“IdeaClip 原生权限验收”窗口实际点击权限提示；后续断言通过 Playwright 读取真实 Chrome 状态。

| 原生步骤 | 已观察到的结果 |
| --- | --- |
| localhost 服务商权限先拒绝、再允许 | 拒绝时无授权、无请求；允许后真实 contains 返回 true，配置保存 |
| 127.0.0.1 网站权限先拒绝、再允许 | 拒绝不启用浏览辅助；允许后真实动态注册生效，新页面自动出现本地提示，无手动注入替代 |
| 采集、明确勾选并保存 | 真实正文提取后，Mock 请求一次并保存报告，不含图片 |
| 暂停、恢复 | 暂停后保存只建立暂停任务；人工恢复后执行一次 |
| 取消运行任务 | 真实客户端连接取消，任务取消，费用不自动退回 |
| 关闭 AI | 当前请求失败/取消，关闭后新保存不入队，也无新请求 |
| 每日预算耗尽 | 在独立测试账本写入已预留当日预算的合成记录；真实引擎检查后任务预算暂停，没有额外 POST |
| 实际撤销网站权限 | 调用真实 `chrome.permissions.remove`，网站 contains 为 false、服务商 localhost 仍为 true；任务中心显示权限被撤销，恢复失败，无新请求 |
| 原生配置关闭 Chrome 后重开 | 同一配置的 5 条任务 ID/状态保留（2 完成、1 取消、1 失败、1 暂停），缺失域名授权时恢复失败，零新请求 |

这些结果来自分段运行，**不是一次完整原生测试无失败通过**：

1. 首次四次人工提示均通过，随后原生动态注入、保存、暂停/恢复、取消和 AI 关闭通过。重启后期待第六次请求的断言失败。检查发现 CDP `Extensions.loadUnpacked` 临时加载扩展在重载时没有保留域名权限；队列安全暂停，没有绕过权限。中断任务记录为未知费用失败，未自动重发。
2. 新测试配置中，用户再次对两个域名点允许，补测预算耗尽和真实网站撤销的断言通过。关闭上下文时，普通测试套件清理共享产物目录，导致 Playwright trace 复制 ENOENT；此次运行结果为失败，不能算整例通过。已将原生输出改为独立 `test-results-native/`，避免共享目录冲突。
3. 使用第二次原生配置、通过 `IDEACLIP_NATIVE_RESTART_PROFILE` 只继续重启检查，实际 1 项通过：数据保留、原生授权缺失时拒绝恢复、没有请求。此模式不重复证明拒绝/授予，前序步骤依据前两次的断言记录。

普通自动套件也真实关闭/重启 Chrome，验证中断不重发、人工恢复有效未发任务，但其域名授权是 Mock。**普通手动安装扩展的授权跨重启持久化仍未验收**，不能把 CDP 临时加载行为当作普通安装结论。

## 运行与安全检查

默认运行 `npm run test:native` 需人依次处理 localhost 拒绝/允许、127.0.0.1 拒绝/允许；`IDEACLIP_NATIVE_GRANTS_ONLY=1` 仅跳过已经独立验收的拒绝步骤，不能单独声称全流程验收。续验变量只用于已知的专用测试配置，不要指向日常浏览器配置。

原生及普通测试分别保存在被忽略的目录，不提交配置、数据库、截图、ZIP、trace 或临时诊断文件。源码无硬编码真实 Key、VITE 凭据或新日志正文；保留仅 `activeTab` / `storage` / `scripting`，没有新增全站安装权限、远程依赖或 AI 请求入口。

## 仍未验收与限制

- 普通安装扩展的权限跨重启行为、Edge、长期无人值守与全面无障碍。
- 真实付费模型未调用；本机 Mock 不能证明 OpenAI/DeepSeek 真实模型能力或账单上限。
- X/微信沿用历史真实页面限制。本轮 X 仅本地可控 DOM 样本；未把用户两个不可读取的真实帖子标为通过。
- 质量规则可能误判；长导航或伪装成正文的公开页面可能通过启发式，完整不代表来源可信。敏感规则、白黑名单及用户授权仍必需。
- 段落定位不是联网证据核验；DOM/URL 改变可能使原网页定位失效，仍可查看保存快照。
- 不包含新依赖、AI 侧边栏、联网深度研究或项目孵化。
