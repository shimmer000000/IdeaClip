# AI 引擎、自动队列与安全约定（IC-007 / IC-008 / IC-009）

入口为 `analysis.html?noteId=…`，只由卡片、完整笔记或编辑页的显式链接打开。设置或打开页面不发送模型请求。`src/ai.ts` 的旧调用接口只提示用户走确认流程，不能绕过 `AIEngine`。

## 请求生命周期

1. 检查 AI 总开关、已保存笔记、未提交编辑、配置、域名授权与对应端点凭据。
2. 构造不可修改的发送快照：标题、采集正文、感悟、脱敏 URL，以及最多 3 张主动选择的本地 PNG/WebP。文本最多 200000 UTF-8 字节，单图最多 2 MiB。未选图时不读取原图；不下载远程媒体。
3. 返回独立的预览副本，显示完整端点、模型、内容、图像、Token 和费用估算。本次确认 ID 只可消费一次，10 分钟失效；改笔记/配置/凭据后重新确认。
4. 用户确认费用与资料；图像另需能力声明和上传确认。Web Locks 在扩展来源内串行处理请求；设置关闭、取消或页面关闭可以中止等待。
5. 在含设置、配置和 `aiUsage` 的事务中预留预算，重新核对门禁后才调用 transport。恢复数据库、配置变化与清除凭据也通过本地通知取消客户端任务。
6. 响应最多 1 MiB，拒绝 HTTP 失败、重定向、拒答、截断和工具调用；不读取服务商错误正文，不自动重试。
7. 对报告执行 JSON Schema 和来源证据校验，检查凭据回显（包含双层 JSON Unicode 转义情形）。成功后生成纯文本/转义 Markdown，按新 ID 保存历史，不修改笔记。失败记录仅含安全状态码、用量与预算。

## 自动模式与持续授权

默认 `manual` 且 `autoEnabled: false`，总开关继续默认关闭。自动模式不会替换手动的逐次确认流程，而是在单独页面确认后建立 `autoPolicy`：精确域名白名单、含子域黑名单、端点配置版本、凭据版本、浏览器会话、授权 ID、文本范围、单次估算费用上限及每日共享预算。每次改模式、配置、凭据或发送范围需重新确认，修改授权会取消旧请求并暂停旧等待任务；旧任务须人工恢复后绑定当前授权。

- `after-save`：仅主动提交已保存笔记的新增/修改版本入队。草稿自动保留、保存草稿、备份导入、批量分类/标签/收藏不触发；没有 URL 的灵感须单独允许。
- `assist`：额外请求精确网站权限，仅在白名单主框架注册 `assist.js`。本地规则识别候选，不调用模型，不自动保存/上传。可信点击提示只创建标题/URL 草稿；用户仍须采集/编辑、勾选本条入队并主动保存。可保持自动分析关闭而只使用本地建议。

自动任务一律零图片，不读取截图 Blob，不允许以自动模式继承手动选图。输入只含标题、采集正文、个人感悟、脱敏 URL；调用同一 `AIEngine` 与已授权模板的 Schema（默认商业模式模板保留 15 栏），保存到原 `analyses` 历史。任务中心的“手动重试”也只发送文本，另外要求新的单次预览及重复费用确认；手动分析页仍保留逐张选图流程。

## 持久队列与取消

schema v7 只新增 `autoPolicy` / `aiTasks`，保留 schema v1–v6 的业务数据及预算账本。笔记提交与任务插入在同一 Dexie 写事务内，唯一 `dedupeKey = noteId:revision:<revision>` 防重复；任务只保存稳定 ID、来源类型、revision、原始文本字段 SHA-256、状态、请求/报告 ID、安全失败原因，不复制正文或原图。

状态为等待、运行、完成、失败、已取消、已暂停。任务中心每次读取 24 条，待处理任务上限 1000，超限/配额错误回滚本次笔记提交，独立编辑草稿仍保留。没有内容变化的重复保存不入队；版本变更、原始字段修改、笔记删除、未提交编辑都会使旧快照失效，不自动换用最新资料。

MV3 worker 不承担长请求，只响应保存通知并打开不抢焦点的 `tasks.html` 标签页。执行页须保持打开；通过 `ideaclip-automatic-owner` Web Lock 选出一个调度者，每个任务另持 `ideaclip-task:<id>` 锁，底层与手动分析共享原预算串行锁。不会用 keepalive 轮询、历史权限或全标签页扫描维持执行。`runtime.getContexts` 仅查找本扩展任务页，旧浏览器缺少该 API 时允许打开额外执行页，任务锁仍阻止重复发送。

执行前、预算事务内、发送前及响应后校验：总开关、策略、授权/会话/配置/凭据版本、任务运行状态、不可变快照、来源白黑名单、单次和每日费用。浏览辅助任务另外检查原网站权限，撤销后即使服务商权限仍有效也不发送。SHA-256 或本地权限查询在短事务中通过 `Dexie.waitFor` 保持活跃，不在事务内等待网络。

暂停/停用自动模式、更新策略、关闭 AI、改配置/凭据、撤销权限、恢复备份时，通过本地通知取消相应客户端 I/O、停止新任务，等待任务转暂停。任何任务失败均暂停后续队列，避免错误连续产生费用。取消单个运行任务不自动重发；取消全部等待只作用于等待和暂停项。服务商仍可能计费，预留不会自动退回；缺失或不可读账本也不能被当作免费。

Chrome 会话中保存随机 session ID，worker 重启复用，整个浏览器重启后更换。新执行者持调度和逐任务锁后核对遗留运行状态：存在已保存报告则恢复完成，否则失败并提示未知费用；同会话执行页意外中断也暂停后续任务。浏览器重启后剩余等待任务转暂停，**不会自动恢复执行**。只有用户点击恢复、凭据和域名权限仍有效、当前授权和快照匹配且尚未发送的任务才重新等待；失败、已取消、已尝试任务不能借恢复自动重发。默认 session Key 丢失时须重填并重新确认自动授权。

## 浏览辅助隐私边界

精确白名单不包含子域；黑名单包含子域并优先，内置敏感规则不能覆盖。密码、银行、邮箱、账户/支付/管理 URL、敏感查询参数及明显敏感字段拦截。content script 在读取正文前检查 URL、密码/信用卡/验证码表单，再读取有限标题、描述和语义片段；每份文档最多 10 次候选规则检查，DOM 更新防抖。不访问表单值、cookies、登录接口、浏览历史或其他标签页，不执行远程分类。

建议置于 closed Shadow DOM，不请求网页媒体。点击必须是可信用户事件；主 worker 再核对来源主框架、当前标签 URL 与权限，才创建草稿。策略或权限撤销时通知现有脚本移除提示；卸载动态注册不被误认为可以移除已经运行的脚本，符合 [Chrome scripting 的已注入脚本说明](https://developer.chrome.com/docs/extensions/reference/api/scripting)。端口失联时停止显示，页面重载后按最新授权检查。

这些是保守本地规则，可能误判或漏判，不保证识别任意私人网站或文本。用户应仅授权公开研究网站，主动用黑名单排除私人站点；本阶段不实现持续浏览器监控、全标签页扫描、联网深度研究或项目孵化。

## 兼容传输与代理

`AITransport.complete(config, key, messages, signal)` 为可替换传输边界，默认使用单次非流式 Chat Completions POST：

```json
{
  "model": "用户配置的模型",
  "messages": [
    { "role": "system", "content": "固定规则与报告 Schema" },
    { "role": "user", "content": "不可信资料 JSON，或明确选择的图像内容数组" }
  ],
  "response_format": { "type": "json_object" },
  "max_completion_tokens": 4096,
  "stream": false
}
```

输出上限参数可配置为 `max_tokens` 或 `max_completion_tokens`，按所选模型文档使用。成功响应为 `choices[0].finish_reason: "stop"` 与 `message.content` JSON 字符串，可附 `usage.prompt_tokens/completion_tokens`。图像使用 `image_url` data URL、`detail: "low"`；不会给服务商可自动下载的远程图片地址。OpenAI 请求额外设置 `store: false`。接口依据 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[OpenAI JSON 模式说明](https://developers.openai.com/api/docs/guides/structured-outputs) 与 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 设计；JSON 模式不替代本地 Schema 校验，具体模型可用性未实测。

官方模式固定端点分别为 `https://api.openai.com/v1/chat/completions`、`https://api.deepseek.com/chat/completions`。自定义兼容 API 可指向用户自有安全代理，支持 Bearer 或“代理自行鉴权、不发送 Key”。代理应在服务端保管模型 Key、实施实际账户预算和来源鉴权，并返回上述响应形状；本项目没有代理后端，也未验证任意第三方兼容服务。

端点仅接受 HTTPS 或本机 HTTP（localhost / 127.0.0.1），禁止用户名密码、查询参数和 fragment。`fetch` 固定完整端点，设置 `redirect: 'error'`、`credentials: 'omit'`、`referrerPolicy: 'no-referrer'`、`cache: 'no-store'`。不尝试自动跟随、重新授权或带 Key 重定向。超时 1 至 120 秒；最大输出 256 至 16384 Token。

## 凭据与权限

`chrome.storage.session` 为默认凭据存储，长期 `storage.local` 需单独选择并确认风险；两者限制为 TRUSTED_CONTEXTS。凭据绑定完整端点与版本，不回填密码框，不存入 Dexie、sync、环境变量、诊断日志、普通 ZIP 或报告。清除密钥时撤销当前主机授权并取消任务。该机制不等同硬件加密，本机恶意软件、调试权限与浏览器配置泄露仍可能读到 Key。优先使用自有安全代理，避免把真正模型 Key 交给客户端。存储能力参考 [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage)。

为凭据添加 `storage` 安装权限；`https://*/*` 与本机 HTTP 仅为可选主机声明。保存配置时通过用户点击申请一个指定主机，不授予安装时全站访问，拒绝后门禁不发送。Chrome 主机权限不区分端口，应用仍逐次校验完整 URL 和配置版本。CSP 允许 HTTPS / 本机 HTTP 连接，仍禁止远程脚本和 unsafe-eval。参考 [Chrome permissions](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

## 报告与提示隔离

固定 JSON Schema 为 `schemaVersion: 1` 和 15 个必填栏目，每栏 1 至 8 条：`kind`（fact / inference / hypothesis）、`text`、`evidence`。`fact` 必须有发送原始文本内的逐字证据，界面显示“来源陈述（未独立核验）”；它不证明原网页说法真实。没有文本证据的图片观察使用推测或假设，未来收入、规模、盈利和成本预测应说明假设及验证方法。

system 规则由应用生成，网页正文/感悟/截图仅位于单独 user 资料，不能建立新系统角色。请求无 tools，不执行网页指令。Schema、证据、类型和长度校验可拒绝不合规输出，但不能保证模型对商业事实、因果或经济假设判断正确。报告应由用户核对，不承诺商业结果。

Ajv 只在构建期编译，提交固定 JSON Schema 和独立校验函数，使用原生 Unicode 码点计数，浏览器不动态编译或 eval。参考 [Ajv standalone](https://ajv.js.org/standalone.html)。`npm run build` 重新生成校验器与许可证；修改栏目需同步 Schema 脚本、类型、提示和测试。

## 预算、历史和数据

配置单价单位为 USD / 百万 Token，每日预算按 UTC 日计算。文本输入采用 system + JSON 的 UTF-8 字节数加 4096 开销；图像另加用户配置的每张 Token 预留；输出按最大输出计。预留微美元为向上取整的 `输入Token估算 × 输入单价 + 最大输出Token × 输出单价`，在事务中与当日预留之和比较，避免并发超用本地预算。

失败、超时、取消及未知结果不自动退回已提交预留，跨 UTC 午夜仍归属于原请求日期。读取失败记录异常也保留已知预留；实际 Token 如服务商返回则记录，只作信息展示。进程中断留下 reserved 状态显示“进行中或结果未知”，不擅自视作免费。

这是基于用户价格与图像假设的本浏览器限制，非实时账单、账户硬限额或跨设备限额，不能抵抗用户修改本地时钟/数据。推理、缓存、图像规则及价格差异可能使费用不同，应同时配置服务商账户限制。AbortController 只取消客户端 I/O，不保证服务商停止运算或计费。自动请求必须处于有效持续授权范围；失败后重新请求必须再次单次确认。

schema v6 新增 `aiConfig` / `aiUsage` 和 `[noteId+createdAt]` 分析索引，不修改旧笔记和图片。报告保存结构化内容、Markdown、模型、来源 origin、时间、输入摘要、笔记 revision 和图像数量，历史按新 ID 追加。保存失败时保留已取得报告，可复制/导出或无费用重试保存。

报告及元数据进入原 `analyses` ZIP；配置、凭据和本地预算不进入 ZIP。完整替换也保留当前 `aiConfig` / `aiUsage`，避免恢复重置预算。旧纯文本报告兼容；新设备重新配置服务商。普通业务表、截图及管理索引继续沿用原有事务和迁移路径。

自动授权、会话和任务状态是本设备执行状态，不进入 ZIP，不跨设备恢复；完整替换保留当前 `autoPolicy` / `aiTasks`。恢复前暂停队列并取消请求，恢复后即使通用 AI 开关为开，旧任务仍需人工核对与恢复，文本/版本变化则失效。新旧 AI 报告继续按原七表格式备份；ZIP v2 新增模板表，并继续读取 v1；现接受 schema 1–9。

第一轮优化新增正文质量门禁：只有关联网页采集为完整、URL 与全文一致、来源段落有效且不是手动编辑或恢复内容，才可自动发送。质量不合格的笔记正常保存，任务保持暂停并显示原因。入队、人工恢复、执行前及引擎既有的多阶段授权检查均复核，不更换引擎或跳过预算。旧记录不自动回填授权；用户仍可在原手动分析页逐次预览确认，不增加截图自动上传。


## IC-009：受限模板与版本授权

`src/skills/model.ts` 独立定义五种内置模板及不同的栏目：15 维商业模式、资源/最小交付/成本/实验/停止条件、竞品证据/细分/替代/差异/壁垒、需求/架构/实施/测试/安全/中文开发指令、起点/7天/30天/90天/依赖/阶段决策。每份定义包括 ID、版本、名称描述、场景、输入要求、提示、栏目结构、输出上限和展示方式；由栏目派生实际 JSON Schema，不接受任意可执行 Schema 或远程 `$ref`。

网页、用户感悟和模板提示均为 user 资料。system 只使用固定安全前缀及应用根据受限字段生成的 Schema；自定义提示、栏目标签与说明不能占据 system、配置工具或修改传输层。占位符只作一次 JSON 转义文本替换，不解释表达式或执行代码。输入要求是供用户核对的说明；资料缺失时模型应提出问题，不宣称已取得未提供的数据。

每个栏目固定为 1–8 条 `kind/text/evidence`，维持 3000/1000 Unicode 字符上限和逐字 evidence 检查。商业模式报告继续使用原 Ajv 预编译 v1 校验器；其余使用受限 Schema 对应的逐字段验证器（测试与 Ajv 编译结果对照），浏览器不运行动态编译、eval 或用户代码。模板 Schema 只能改变栏目集合，不改变安全证据类型。

`AIEngine.preview(noteId, imageIds, templateId?)` 冻结模板定义、最终 system/user 文本及输出上限，输入摘要含展开后的模板偏好。模板本体、Schema 和展开后的文本计入原 Token/成本估算；输出上限取模板与服务商配置较小值。预留、发送前和响应后复查模板未删除/停用、版本及完整定义未变，模板变更广播也会取消客户端 I/O。失败/中断仍保留预算且不自动重试。

`autoPolicy` 另绑定 `skillId/skillVersion/skillSignature/skillPreferenceVersion`；任务固定 ID、版本和完整定义摘要文本（规范化定义，不作为密码学签名）。默认项变更或任何模板管理写入使本机偏好版本轮换、暂停队列并取消请求；保存自动授权前显示且校验当前默认模板。旧无绑定任务保留，恢复不会补写新模板；重新授权后旧任务模板不同则继续暂停，用户可取消旧项并逐次手动分析。模板更新不能以保存相同笔记版本为由自动重发。

schema v9 新增 `aiTemplates/skillPreferences`，不重建旧表。`analyses.template` 保存脱敏的完整定义快照，非商业模式结构存 `skillReport.schemaVersion: 2`；旧 report/纯文本照常显示。报告另保存分析时脱敏来源 URL，证据摘录可对照原网页（页面可能变化，不代表核验）。历史展示和复制无需模板仍存在。Codex 指令的复制只是文本，不产生开发任务或执行命令。

模板与报告进入 ZIP v2 的字段白名单，恢复后模板停用；导入 JSON 总是新的停用身份。默认模板选择与偏好版本留在本机，不进入 ZIP，恢复原事务轮换偏好版本，使旧授权失效。配置、凭据、任务、预算仍不导出；没有新增依赖或权限。详见 [IC-009 验收](IC-009-VALIDATION.md)。


## IC-010：手动多灵感对比

`AIEngine.previewComparison(ids)` 规范化 2–10 个有序唯一 ID，使用固定应用对比 Schema，不依赖用户启停的商业模式模板。读取已保存笔记并拒绝未提交编辑，冻结每项 ID/revision/updatedAt、原始输入字段 SHA-256 和脱敏文字。总资料含 JSON 开销最多 200000 UTF-8 字节，超限抛错，不自动截断或发送部分项目。仅图片数量为 0；不写自动任务。

复用原引擎的 run、开关、完整端点/凭据授权、预算锁、一次性 ID、10 分钟有效期、超时、取消和响应上限。对比额外在执行前、预算事务内、发送前和返回后核对每个来源摘要与未提交编辑；禁止带 AutomaticAuthority，资料改变则整体失效。对比输出上限使用用户服务商配置（而非被商业模式模板限制为 4096）。较多项目需要足够输出预算；截断会明确失败，不自动重试。

固定 Schema 为每项目 12 个维度，每维 0–10 参考分及 Claim 数组，另有优势、劣势、未知、风险、任务、理由、7天计划和停止条件。与 Schema 对应的受限验证器检查数量、额外字段、项目身份、分数和逐字证据；事实证据只能来自本项目，不能引用其他项目冒充。数据及网页指令只在 user JSON，system 固定禁止联网/工具/泄露/编造真实收入。

五项权重为 0–100，至少一项非零，加权分=sum(weight*score)/sum(weight)。全部评分正向化，低成本/低难度/低风险对应高分。调整权重是纯本地函数，排序建议由此产生，原模型理由/计划不重新生成。历史保存原始评分，当前查看偏好默认等权。

schema v10 新增 comparisonReports，来源为软引用；旧笔记删除不能级联删除对比。报告含来源脱敏快照以保留证据，显示当前记录变化或缺失。ZIP v3 白名单新增该表，继续排除凭据与执行授权，兼容旧格式。无新 API、依赖或权限。测试与限制见 [IC-010 验收](IC-010-VALIDATION.md)。


## IC-011：项目待审核方案

`AIEngine.previewProject(projectId, selectedNoteIds)` 复用原 preview/run，而非另建传输引擎。固定应用 Skills 定义 `builtin-incubation` v1.0.0；八个独立栏目为 MVP、架构、任务、验收、7/30/90 天计划和风险/停止条件。每栏1–8条 Claim，来源陈述逐字证据校验，推测/假设标明类型，模板偏好与项目/笔记资料只进入不可信 user JSON。输出取服务商与模板8192 Token较小值，资料200000 UTF-8字节上限；超限报错而非自动丢弃。

只发送预览中的项目业务字段和0–10条主动选择的已保存笔记；不发任务、阶段历史、旧方案或截图，也不接入自动队列。总开关、一次确认、10分钟有效期、域名/凭据/配置、预算预留锁、取消、超时、无重定向和安全日志全部沿用。项目整行和每条笔记原始字段使用摘要，在执行、预算事务、发送前和返回后复查；变更或缺失须重新确认，不自动重试付费请求。

方案存入 projects.plans，保留模型、时间、模板版本、生成时项目版本及笔记ID/revision/hash。保存失败结果留在页面，可重试存储而不请求模型。生成仅追加历史，不变业务字段、任务或阶段；随后须重新读取并人工审核选中任务，再以事务版本检查和 planId:index 稳定键导入。同一任务删除后仍保留导入标记，不能被重复确认重新创建。

Codex 指令由已审核任务及项目资料本地组合，包含背景、目标、技术要求、范围、验收、测试和Git要求；只复制纯文本。项目中心没有命令执行、GitHub建库或联网研究接口。AI方案属于建议，不代表真实技术/商业验证。真实模型的效果仍未验收。
