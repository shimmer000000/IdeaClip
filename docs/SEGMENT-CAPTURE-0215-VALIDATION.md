# 0.2.15 超长网页分段截图验收

日期：2026-11-10。基线：6a955aec19fbbddba5cf198f8d2e4e02cc3157f5（0.2.14）。开始工作区干净。

## 观察与处理

用户截图显示“网页过长：最多20000 CSS像素、40屏”。这能证明当前操作触发整页长度保护，不能据此确定网页实际高度。0.2.15不提高或移除该保护，新增明确的分段模式。没有读取截图中的私人网页或调用AI。

## 使用步骤

1. 在目标网页滚动到希望开始的位置，等待页面加载稳定，点击IdeaClip的“分段截长图”。
2. 每次仅截图一段，自动滚动后恢复起点；Esc、滚轮、点击或切换页面可取消。取消/失败不保存半成品。
3. 预览显示“分段长图（非完整网页）”及本段起止位置/页面总高度，图片可以下载或整理为灵感。
4. 尚有后续内容时，明确点击“继续下一段”，才从已保存的上一段末尾截取下一张。旧图保留，不自动连续截图、合并整页或删除前段。
5. 笔记编辑页也可从原网页当前位置截一段并加入当前草稿；编辑页不自动补截后续，预览页提供手动继续入口。多张图片仍须按需关联同一笔记。

原用户Chrome需加载0.2.15构建才有新按钮；不能把隔离测试版本视为原Chrome已更新。

## 实现与边界

- 整页模式仍拒绝超过20000 CSS像素或40屏的网页。每段按视口高度取不超过20000 CSS像素和40帧的范围；保留输出宽1600、高24000、3200万像素及6MiB上限。
- 从实际scrollY保留分数位置。每帧含首帧保留1 CSS像素重叠，只绘制范围内新像素，以处理浏览器缩放滚动量化；输出不包含范围外像素。
- 延续位置只读已保存图片的有限范围元数据，不接受调用方传入任意偏移。原标签/URL、页面高度或视口变化拒绝继续；每帧仍复查活动来源、缩放、尺寸和位置。
- 保留原fixed/sticky隐藏、动画暂停、finally恢复与90秒页面看门狗。原网页关闭/导航只能尽力清理，不能保证恢复已经不存在的文档。
- 横向、主要独立滚动容器及超复杂DOM仍拒绝。无限加载导致高度变化仍停止；高度稳定也不证明正文未替换。到达页面底部不等于此前全部内容已截图，界面明确提醒人工核对。
- 未增加权限、依赖、网络请求或AI调用。未操作真实笔记、费用账本、SSH、8788/23334服务或其他项目。

## 存储与备份

沿用现有Dexie表和版本，仅新增segment类型及可选五字段captureRange。每段Blob及范围独立保存，旧visible/region/full图片保留。范围只接受有限数字、合法边界、最大段长度和固定字段；ZIP v6恢复同时校验，拒绝越界/未知字段。

旧ZIP可恢复，包含segment的新ZIP要求0.2.15或更新客户端；不声称旧客户端支持新类型。恢复图片sourceTabId=0，不恢复原标签继续能力，需从目标网页重新开始。
