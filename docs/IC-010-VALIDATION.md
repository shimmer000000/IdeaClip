# IC-010 多灵感商业机会横向对比验收

日期：2026-11-07。基线：87ddc79e98173496d5a3de0c431c7cef4c9b5dca。main 已拉取，已阅读 AGENTS、AI-ENGINE、ROADMAP，并用 CodeGraph 检查笔记、Skills、引擎、队列、历史与备份。范围仅多灵感对比，不含联网研究和孵化。

## 功能与安全

管理中心多选后进入独立对比视图（复用 analysis.html 的 compare 参数），支持 2～10 条已保存记录，重复 ID 去重且保持顺序，移除与上/下移，显示来源、正文质量、正文和感悟。草稿/缺失/未提交编辑拒绝发送，不能静默排除。超过 200000 UTF-8 字节的 JSON 资料明确要求缩减，不截断项目或正文。

对比是固定应用模型，独立于可启停的 Skills；通过原 AIEngine.previewComparison/run 处理，一次性逐次确认、总开关、完整端点与凭据、每日预算锁、超时/取消、重定向拒绝和响应限制均保留。不发送截图、不读 Blob、不建立自动任务、不访问来源 URL。预览显示全部资料、来源版本、最终 system/user 文本、输入 Token 上界和费用预留。

来源冻结 ID/revision/更新时间及原始标题、URL、正文、感悟、保存状态的 SHA-256。执行前、预算事务内、发送前、返回后复查全部来源，任何变化/缺失或未提交编辑整次失效，不替换为新内容。执行期间取消仍可能计费，保留预算，绝不自动重试。

报告固定 12 维：需求、市场、盈利、开发、初期资金、运营、获客、竞争、复制、合规、小团队可行性及最小验证。每维包含 0～10 参考分和有类型的来源陈述/推测/假设；另含优势、劣势、未知、风险、任务、排序理由、7天计划及不投入条件。验证器与固定 Schema 对应，检查字段/数量/分数及逐字证据；事实只能引用本项目资料，不能挪用其他项目原文。UI 纯文本展示，模板及网页不能创建系统权限或工具。

资金、开发、获客、盈利、风险五项权重 0～100，至少一项大于零。所有分数正向化：低成本/低难度/低风险对应高分。排序为 sum(weight*score)/sum(weight)，只用保存评分本地重算，不产生请求。UI 明示是启发式而非市场验证；原理由和计划不会因权重变化重新生成。权重为当前查看偏好，重新打开历史回到等权；复制和 Markdown 包含当前权重、评分表与排序。

报告自动保存到新增 comparisonReports，可重试保存（不请求模型）、历史分页、复制、Markdown 导出及重新选择来源分析。来源为软引用，删除笔记不删除对比报告；保留当时的脱敏正文快照并提示当前来源变化/缺失。重新分析必须重新预览确认。

Dexie v10 仅新增 comparisonReports，不删除/重建旧库。ZIP v3 新增第九业务表，包含来源 ID/revision/hash 和脱敏文字、报告/模型/时间；先 Schema/证据校验再按白名单处理。原笔记已删除也能备份恢复报告，不创建悬空强引用。兼容旧 v1/v2 与 schema1–10，旧清单缺少对比计数时在旧版本范围按 0；未来版本拒绝。配置/Key/账本/执行授权不导出，恢复仍暂停自动任务且原事务回滚策略不变。

## 限制

真实付费模型、Edge、全面无障碍与长时压力未验收。10 项完整输出可能需要提高服务商输出 Token 和预算，截断会失败而不自动重试；Mock 不证明真实模型可稳定生成所有栏目。评分不代表商业事实或盈利保证，权重也不改变原建议的假设。原 X/微信及普通安装权限跨重启的既有边界不变。无联网、截图自动上传或项目孵化。
