## 覆盖

新增 38 项单元测试：

- 默认关闭、开启/预览不请求、一次性确认、返回快照不可篡改，未保存/未提交笔记拒绝。
- 域名权限、缺失密钥、配置/笔记/凭据变更、10 分钟过期、关闭与排队取消。
- 固定 system + 独立 user 数据、无 tools、只发送主动选图、文本模型拒图、无选图不读 Blob。
- 凭据不进入预览/日志/失败账本，明文及双层 Unicode JSON 回显拒绝，Markdown 和报告备份脱敏。
- 超时、HTTP 失败、重定向、请求/响应大小、危险端点、官方固定 URL 与兼容参数、代理无 Key 模式。
- 并发预算事务、失败记录、预留不退、跨 UTC 午夜归属、账本读取异常不清零预留。
- 15 栏 Schema、缺字段/额外字段/错误类型/枚举/空数组/超长/空对象、来源证据检查，无效 JSON 不保存。
- 历史新版本、重复保存幂等、日志或报告存储失败仍保留结果、保存重试不增加调用、HTML/Markdown 转义。
- 结构化报告与模型时间 ZIP 往返、凭据配置与账本排除、替换保留本地预算、v5 → v6 保留原笔记、Blob、分析和设置。

新增 8 项真实 Chrome + 本机 HTTP Mock 集成测试：

- 默认关闭、保存配置不发请求、逐次内容/费用确认、取消无请求、报告保存/复制/Markdown/历史与重载。
- 权限拒绝、真实会话存储、清除/撤销阻止请求，长期保存风险确认及浏览器重启后会话清除/本地保留。
- 图像默认不发送、能力开关、主动选择、单次上传确认、模型能力变化清空旧选择。
- 一个请求进行中、另一页面排队时关闭总开关，两者取消；笔记管理及 ZIP 仍正常。
- Schema 错误、超时、凭据回显不存报告，重新确认后才重试。
- 每日预算阻止发送；真实 302 响应不跟随，第二个本机端点未收到请求/密钥。
- AI 报告随完整 ZIP 恢复，凭据/配置不进入 ZIP，本地预算记录不被恢复重置。

原生 Chrome 主机授权弹窗作为测试边界 mock（仅批准本机测试主机），拒绝路径也覆盖。Chrome storage、IndexedDB、fetch、CSP、Web Locks、AbortController、下载/复制、进程重启和本机 HTTP 服务均为真实执行；测试路由拒绝其他 HTTP/HTTPS 出站，不能据此宣称原生弹窗或官方模型已验收。

## 安全边界和遗留

- 没有硬编码真实密钥，不用 VITE_* 传密钥。凭据仅受信任上下文读取；会话默认，长期本地保存需显式风险确认。私密截图和笔记仍由用户在发送前核对，脱敏不能识别任意图片中的秘密。
- 精确端点绑定、可选主机授权、拒绝重定向、无 cookie/referrer；错误只保存安全状态，不保存原始服务商错误正文。响应凭据回显被拒绝，日志与 ZIP 的合成 Key 检查通过。
- JSON Schema 与来源证据检查不保证模型事实正确，也不能承诺抵御所有模型层语义诱导；不提供脚本或工具执行路径，渲染为纯文本。
- 本地预算是用户价格假设下的预留限制，非账户账单硬限制。取消和进程中断后服务商可能仍计费，预留不自动退回；跨设备、时钟修改与真实价格变化不受客户端保障。
- 未测试真实 OpenAI/DeepSeek 账户、任何真实模型的图像/JSON 能力、原生主机权限弹窗与 Edge。仅支持当前 Chat Completions JSON 配置，额外协议/流式/代理后端不在本阶段。
- 既有 X 真实正文、微信真实文章和全面无障碍的验收限制继续保留。
