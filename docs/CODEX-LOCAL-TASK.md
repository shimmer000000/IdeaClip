# 0.2.3 受信任 Windows 本地单任务

本模式取代“必须先建立额外 OS 隔离”的开发方向。用户已取消 Windows Sandbox、Hyper-V、虚拟机和容器建设。原 0.2.1 Mock 门禁和 0.2.2 固定 WASM 合成程序仅保留作历史回归；其 `REAL_EXECUTOR_DISABLED` 不作为新本地模式的 OS 前置条件。

## 使用流程

1. IdeaClip 中审核一项软件开发任务，绑定明确仓库、绝对工作目录和有限相对路径，导出任务包 v1。人工研究和验证测试不转换成开发任务。
2. 运行本地一次性助手 `npm run handoff:task -- preview`，独立提供下列参数。只检查 Git 和 CLI 元数据，不启动模型。不要将整份包文本拼接进 shell。
3. 核对完整预览；若要真实执行，必须另行批准这一项，再以同样参数使用 `run-once`。助手只在真实 TTY 中接受本次随机确认短语，不接受 `--yes`、管道批准、包内授权字段或授权 JSON。
4. 一次运行结束，检查忽略目录 `private/local-task-runs` 中的运行摘要。仅成功完成、最多一个新本地提交、工作区干净且全部变更属于原路径范围时产生 `IdeaClip-Delivery-*.json`（交付 v2）。
5. 在交接中心主动选择交付文件，检查后导入。继续使用独立本地测试记录、GitHub/CI 核验和人工验收；不自动通过或完成任务。

固定参数模板（示意占位符必须由操作者明确提供）：

```text
npm run handoff:task -- preview
  --package <任务包绝对路径>
  --workspace <同一绝对工作目录>
  --repository <GitHub HTTPS仓库>
  --project-id <项目UUID> --task-id <任务UUID>
  --branch <预期分支> --allow-path <原有相对范围，可重复>
  --codex-executable <已安装codex.exe绝对路径>
  --model <明确模型> --timeout-ms 300000
```

上面换行仅用于说明；实际使用须按终端语法传递独立参数。浏览器没有系统命令桥接，不从导入 JSON 运行命令。

## 授权与预检

- 包 v1/hash/类型/仓库/工作目录复用原校验器，核对 raw/effective Git origin、HEAD、当前分支、索引、脏状态、冲突、链接/嵌套仓库及有限范围元数据。脏目录拒绝，不 stash、不 reset。
- 独立策略不能被包扩大，预览展示全部当前任务及实际固定 argv。包的任意 `instructions` 不拼接为程序命令或执行提示，目标/备注/验收作为不可信任务数据传给固定边界提示。
- CLI 版本、帮助及文件指纹也绑定；不读取或输出登录凭据。项目 `.codex/config.toml` 存在时阻塞，需先单独审查，不通过加载未知执行配置来继续。
- 预览 5 分钟、授权最多 2 分钟，墙钟/单调钟共同核对。授权为当前控制器私有对象，任何异步操作前先消费；JSON、其他会话、其他模式、重启和恢复不能重放。模型/超时/任务/Git/范围变化失效。
- 跨进程使用目标目录哈希命名的排他锁；执行器未确认进程停止时保留锁，不自动删除“过期”锁后再试。须人工核对现场。

## CLI 与费用边界

2026-11-09 本机只读确认 `codex-cli 0.167.0-alpha.3.2`。固定真实启动策略：

```text
codex --no-daemon --ask-for-approval on-request exec
  --sandbox workspace-write --cd <明确目录> --model <明确模型>
  --ephemeral --ignore-user-config --json -
```

`spawn` 使用分离 argv、`shell:false`、普通权限和任务 stdin；没有危险全权限绕过、自动批准、`--search`、`--add-dir`、跳过 Git 检查、续跑或后台循环。若普通权限不足或需要交互升级，失败停止，不降级到绕过模式。执行参数须在本机版本/help 实际支持，否则拒绝。

环境仅传递有限 OS/路径和已有 Codex 登录目录变量，不继承 API Key、任意环境变量或 `NODE_OPTIONS`。不复制、显示或导出登录文件。真实运行仍可能访问模型服务、消耗当前 Codex 账号用量；本助手不能预估账号实际单价或强制美元硬上限。必须逐次批准，不触及 IdeaClip 原 AI/研究费用账本。

参考[官方非交互说明](https://developers.openai.com/codex/noninteractive/)；实际参数以本机帮助为准。本轮没有执行真实 `codex exec`，因此参数组合与真实模型端到端仍待单次授权验收。

## 结果与失败处理

- 只收集有界 JSONL 数字用量和有限 CLI 测试事件，不保存原始 stdout/stderr、模型正文或任意命令日志。仅识别固定的 `npm test` / `npm run test` / `build` / `typecheck` / `test:e2e` 完整命令；无法识别的 shell 包装命令不猜测为已测试。时间为本地观察区间。
- 测试事件仍是 Codex CLI 声明，`localRecordId=null`；不能当独立测试日志。独立记录继续走 0.1.7 文件核对流程。
- Git 后检使用 NUL 分隔文件名、无重命名压缩，检查新增、删除、已提交/暂存/未暂存和非忽略未跟踪文件。范围外修改或绑定变化停止回收，不生成有效交付，保留现场。不自动 rollback、commit、push、部署或合并；只允许任务自身在确认范围内创建至多一个中文本地提交。
- 失败、取消、超时均消费授权，不自动重试。只终止本次拥有的子进程树；不能确认停止时记录 `PROCESS_STOP_UNCONFIRMED`，不继续后检/回收并保留锁。其他项目和现有服务不操作。
- 本机运行摘要只在被忽略的私有产物目录保存；正式交付走现有 v2 脱敏/绑定/版本追加校验，ZIP 仍只含现有有限交付元数据，无执行授权、绝对工作目录、凭据或完整日志。

## 明确不能保证的边界

这是受信任同用户工作区模式，**没有额外 OS 隔离**。预检、模型提示、`workspace-write`、Git worktree 和执行后 diff 均不是指定子目录的强制文件/网络访问控制。不能排除同权限恶意程序、并发文件变化、忽略文件或仓库外访问、脱离父进程的子进程和额外网络操作。任务/项目及其本机规则应由用户信任；后检发现异常只能停止后续流程并保留证据。不能将本轮 Mock 通过称为真实模型执行或 OS 隔离通过。
